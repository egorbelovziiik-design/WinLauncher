# 🌙 DREAM SIMULATOR: NIGHTMARE WORLDS

Хоррор-игра для Roblox на Luau. Готовое место: **`DreamSimulator.rbxl`**
(рядом лежит `DreamSimulator.rbxlx` — тот же проект в XML).

Версия сборки: **2.0.0** · 8 299 объектов · 7 153 детали · 29 скриптов ·
11 экранов интерфейса · 10 снов · 40 заданий · 14 монстров.

## Как открыть
1. Скачай `DreamSimulator.rbxl`.
2. Roblox Studio → **File → Open from File…** → выбери файл.
3. Нажми **Play** (F5).

Появится кинематографичная заставка, затем 3D-спальня с меню поверх неё.
Лечь спать можно кнопкой «ИГРАТЬ», клавишей **M** (меню) или подойдя к кровати
и нажав **E**.

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| SHIFT | бег (тратит выносливость и привлекает монстров) |
| E | взаимодействие (NPC, предметы, портал, кровать) |
| F | фонарик (тратит батарею) |
| Q | использовать расходник (зелье/батарейка) |
| TAB | журнал заданий |
| 1–9 | выбор варианта в диалоге NPC |
| M / ☰ МЕНЮ | меню и пауза |
| F8 | диагностика (сборка, режим данных, FPS, ошибки) |

На телефоне вместо клавиш — экранные кнопки: бег, действие, фонарик, предмет.

## Фонарик и батарея
- Фонарик доступен всегда: базовый луч 44 м.
- Магазин: «Фонарик» (150) — 62 м, «Лампа сновидца» (300) — широкий луч 76 м.
- Заряд 100 %: расход 0,38–0,78 %/с в зависимости от предмета, медленная
  подзарядка при выключенном свете.
- Батарейки: зелёные блоки по карте (+35–55 %), NPC за 55 монет (+80 %),
  расходник «Батарейка» (Q) +75 %.
- Включённый свет помогает видеть, но монстры замечают игрока на 45 % дальше.
- Низкий заряд или низкий рассудок — луч мерцает.

## Что внутри
- Лобби-спальня `Workspace.MenuBedroom` с меню поверх 3D-сцены.
- Магазин (10 предметов + расходники), инвентарь с экипировкой, достижения,
  статистика, настройки (музыка, звуки, качество, чувствительность, сила
  скримеров, тряска камеры, подсказки).
- 10 снов: лес, школа, город, больница, цирк, затопленный город, лёд, фабрика,
  станция, замок — с постройками, реквизитом, светом и туманом.
- 14 монстров (5 архетипов + тематические), PathfindingService, скримеры,
  «Наблюдатель» замирает, когда на него смотрят.
- 40 заданий (обязательное + 3 случайных необязательных в каждом сне),
  NPC с диалогами: задания, лечение, слухи, торговля, батарейки.
- Таймер 600 с на сервере, портал пробуждения, экран итогов,
  бесконечный цикл «меню → сон → пробуждение».
- Сохранение профиля в DataStoreService с серверной валидацией.
  Если DataStore недоступен (например, в Studio без API), игра работает
  на профиле в памяти — это видно в диагностике (F8).

## Проверки качества
Сборка невозможна, если проверки не прошли — «сломанный» файл просто
не создаётся:

```bash
node tools/luaucheck.mjs      # синтаксис всех .luau
node tools/contentcheck.mjs   # данные: сны, квесты, предметы, монстры (fengari)
node tools/wirecheck.mjs      # UI-элементы, кнопки, каналы, атрибуты
node tools/requirecheck.mjs   # каждый require() указывает на модуль
node tools/domcheck.mjs       # классы/свойства/enum по API-дампу Roblox
node tools/checkmaps.mjs      # маркеры карт стоят на полу
node tools/build.mjs          # сборка + все гейты автоматически
node tools/verify.mjs build/DreamSimulator
```

`npm run all` запускает всё подряд.

## Звук
Основные звуки — `rbxassetid://`; если конкретный ассет недоступен
(в Roblox чужие аудио часто закрыты правами), клиент через 0,3 с
автоматически переключается на встроенный `rbxasset://`-звук с нужной
высотой тона. Игра не остаётся молчаливой даже без разрешений на аудио.

## Защита от застреваний
На сервере работает «сторож» (раз в 5 с): если игрок завис в засыпании
дольше сна + 30 с или мир сна пропал, он возвращается в лобби с записью
в лог, а не остаётся с пустым экраном.

## Известные ограничения
- Проверки статические (сборка, данные, API, связи). В Roblox Studio игра
  не запускалась — здесь нет Studio.
- DataStore работает только при включённом «Studio Access to API Services»;
  иначе прогресс живёт до конца сессии.

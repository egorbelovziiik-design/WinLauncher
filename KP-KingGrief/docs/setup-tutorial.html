🛡️ КП-KingGrief — установка с нуля

12 шагов от пустого Discord-аккаунта разработчика до работающего бота контроля персонала. Время: ~15 минут. Ничего в коде править не нужно — всё настраивается командами внутри Discord.

Что понадобится: права Администратора на сервере KingGrief, установленный Python 3.11+ или собранный КП-KingGrief.exe, и 15 минут времени.

1 Создать приложение

Регистрируем «личность» бота в Discord. Это бесплатно.

  1. Откройте discord.com/developers/applications и войдите в свой аккаунт.
  2. Нажмите синюю кнопку New Application в правом верхнем углу.
  3. Введите имя КП-KingGrief → поставьте галочку согласия → Create.

2 Включить Privileged Intents

Без этих двух переключателей бот не запустится вообще.

  1. В меню слева выберите раздел Bot.
  2. Прокрутите до блока Privileged Gateway Intents.
  3. Включите оба переключателя и нажмите Save Changes внизу.
Developer Portal → BotСХЕМА
Settings
General Information
Bot
OAuth2
Privileged Gateway Intents Без них бот выведет ошибку PrivilegedIntentsRequired
SERVER MEMBERS INTENTБот видит роли участников — ищет сотрудников по должностям
MESSAGE CONTENT INTENTБот читает текст сообщений — распознаёт отчёты
PRESENCE INTENTНе требуется — можно не включать
Самая частая ошибка установки. Забытые Intents выглядят как «бот не работает», хотя токен верный. В логе будет строка PrivilegedIntentsRequired.

3 Скопировать токен

Токен — это пароль бота. Показывается один раз.

  1. Там же, в разделе Bot, блок Token → нажмите Reset Token.
  2. Подтвердите (может попросить пароль или 2FA).
  3. Нажмите Copy и сразу сохраните токен в блокнот.
Developer Portal → Bot → TokenСХЕМА
Token

Токен не встраивается в EXE — специально. Он будет лежать в файле .env рядом с программой. Если токен утечёт — кто угодно сможет управлять ботом. Не публикуйте его и не отправляйте в чаты.

4 Собрать ссылку приглашения

Отмечаем scopes и права — портал сам соберёт URL.

  1. В меню слева → OAuth2 → OAuth2 URL Generator.
  2. В Scopes отметьте bot и applications.commands.
  3. В Bot Permissions отметьте 7 прав из списка ниже.
  4. Скопируйте URL из поля Generated URL внизу.

6 Выстроить иерархию ролей

Критичный шаг. Если роль бота окажется ниже контролируемых — Discord физически не даст снять должность, и бот честно напишет «не могу снять роль».

  1. Настройки сервера → Роли.
  2. Перетащите роль КП-KingGrief выше всех должностей персонала.
  3. Проверьте, что роли называются ровно как в списке справа.

Названия должны совпадать посимвольно, включая точки. «Мл. модер» с пробелом не найдётся. Бот ищет роли именно по названию — и не выдумывает ID. Расхождения покажет команда /sync в блоке «🔴 Не найдены роли».

7 Создать файл .env

Три строки — и бот знает, кто он и где работает.

  1. Создайте папку, например C:\KingGriefBot\.
  2. Положите туда КП-KingGrief.exe (или весь проект, если запускаете из исходников).
  3. Создайте в этой же папке текстовый файл с именем .env — именно с точкой в начале.
Блокнот — .envСХЕМА
# обязательно
DISCORD_TOKEN=MTIzNDU2Nzg5.xYzAbC.dQw4w9WgXcQ_ваш_токен

# ваш Discord ID — полные права над ботом
OWNER_ID=123456789012345678

# ID сервера — команды появятся мгновенно
TEST_GUILD_ID=987654321098765432

Где взять ID

Discord → Настройки → Расширенные → включите Режим разработчика. После этого правой кнопкой по себе → Копировать ID, по серверу → Копировать ID сервера.

Про TEST_GUILD_ID. Без него команды синхронизируются глобально — Discord может показывать их с задержкой до часа. С ним появляются за секунды. Для одного сервера оставляйте всегда.
Windows прячет расширения. Включите вид расширений: Проводник → Вид → Показать → ✅ Расширения имён файлов. Иначе файл сохранится как .env.txt и бот его не увидит.

Роль снимется только после нажатия «✅ Подтвердить снятие» — и только уполномоченным администратором. Снимется ровно Модер, посторонние роли бот не тронет. Если у человека несколько должностей — появится выпадающий список для выбора конкретной.
После теста откатите: /clearwarns @сотрудник и верните роль вручную.

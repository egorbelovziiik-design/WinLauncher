📄 Готовый .env

Заполняется автоматически…
Сохраните как файл .env (с точкой в начале) рядом с КП-KingGrief.exe. Токен впишите сами — он показывается один раз в разделе Bot → Token → Reset Token.
Никому не отправляйте токен. Ни в чаты, ни «помощникам», ни на скриншотах. Токен = полный контроль над ботом. Я его не запрашиваю и не увижу.

🧭 Что делать дальше

  1. В разделе Bot включите SERVER MEMBERS INTENT и MESSAGE CONTENT INTENT → Save Changes. Без них бот не запустится.
  2. Откройте ссылку выше → выберите сервер KingGrief → Продолжить → Авторизоваться.
  3. Настройки сервера → Роли → перетащите КП-KingGrief выше ролей Админ / Гл.Модер / … / Стажер.
  4. Положите .env рядом с EXE, впишите токен, запустите КП-KingGrief.exe.
  5. В Discord: /sync — проверить каналы и роли, затем /ot.
Владельцем бота вы станете автоматически — в момент создания приложения. Дополнительно ваш ID уже прописан в OWNER_ID ниже: это даёт уровень OWNER внутри бота (полные права над командами и настройками).

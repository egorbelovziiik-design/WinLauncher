# ❄ KINGGRIEF — НОВОГОДНЯЯ СБОРКА REALLYWORLD v4.0 (ПОД КЛЮЧ)

Полная авторская сборка **ReallyWorld (Рилик)** с огромным отдельным миром спавна, 22 рабочими NPC (включая Бафовара), 11 Шалкер-Кейсами, 5 Боссами Ивентов со стековыми BossBar сверху экрана, богатыми китами строго по привилегиям, Мега-Ресурспаком v4.0 и собственной системой `/lp` + **Web LP Editor**!

---

## ⚡ БЫСТРЫЙ ЗАПУСК ЗА 30 СЕКУНД (БЕЗ ПЛАТНЫХ И СТОРОННИХ ПЛАГИНОВ!)
1. Распакуйте содержимое папки `server/` в корень вашего сервера **Paper / Purpur `1.21 – 1.21.11`** (идеально работает на `1.21.4` и с `ViaFabricPlus 26.2`).
2. Убедитесь, что в папке `plugins/` лежат:
   - **`KingGriefCore.jar`** (v4.0.0 — всё ядро сборки и спавна в одном JAR!)
   - **`KingGriefBridge.jar`** (облачная авто-выдача доната, кейсов и LP с сайта `https://kinggrief.vercel.app`)
   - *(Важно: если от старой сборки в `plugins/` оставались пустые `Citizens`, `FancyNpcs` или `DecentHolograms` — они не мешают, но их можно смело удалить, так как `KingGriefCore.jar` сам строит мир, всех 22 NPC и все голограммы без багов!)*
3. Запустите сервер и выдайте себе главного владельца в консоли:
   ```
   lp user ВашНик parent set owner
   ```
4. В игре введите `/spawn` (или перестройте спавн вручную при необходимости командой `/kgadmin rebuildspawn`).

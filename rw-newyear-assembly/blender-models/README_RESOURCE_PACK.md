# KINGGRIEF: генерация ресурс-пака v66

`build_rp_v66.py` создаёт `../kinggrief-mega-rp-v66.zip`; при заданном
`KINGGRIEF_RP_RANKS_ZIP` создаёт и отдельный ранк-пак, не затрагивая чужой
`kinggrief-ranks-pack.zip`. Требуются Python 3, Pillow и NumPy.

```sh
KINGGRIEF_RP_RANKS_ZIP=../../kinggrief-ranks-pack/kinggrief-ranks-pack-v66.zip python build_rp_v66.py
python test_resource_pack.py
```

ZIP воспроизводим при одинаковых версиях библиотек. `item-model-map-v66.json`
сопоставляет базовые материалы и CustomModelData с моделями. Шары — полноценные
6×6×6 кубы с непрозрачной квадратной текстурой на каждой грани, отдельно
уменьшенные в руках и интерфейсе. Тесты проверяют геометрию, текстуры, таблицы
legacy/1.21.4+, каждый glyph рангов, неизменность старых версий и состав сборки.
Реальный графический клиент этими тестами не заменяется.

Core/Hub мигрируют только известные официальные URL/SHA v63, v64 и v65;
сторонние URL и неизвестные SHA сохраняются. Старые опубликованные версии не
перезаписываются. При изменении ZIP обновите SHA-1 и копии в конфигурациях,
публичном каталоге и сборке. Подробности установки — в `../README_УСТАНОВКА.md`.

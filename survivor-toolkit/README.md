# Survivor Toolkit

Клиентский мод для **Minecraft Java Edition 1.21.11**: осторожные средства для выживания, ручной калькулятор цен, настройка управления и ограниченная локальная камера. Исходный WinLauncher не изменяется.

## Подтверждённые версии инструментов

| Компонент | Версия |
|---|---|
| Minecraft Java | **1.21.11** |
| Java (JDK для сборки и JVM игры) | **21** |
| Fabric Loader | **0.18.4** |
| Fabric API | **0.141.1+1.21.11** |
| Yarn mappings | **1.21.11+build.4** |
| Fabric Loom | **1.14.10** |
| Gradle Wrapper | **9.2.1** |

Minecraft 1.21.11 [официально выпущена Mojang](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11). Fabric [официально поддерживает 1.21.11](https://fabricmc.net/2025/12/05/12111.html), рекомендуя Loom 1.14 и Loader 0.18.1 или новее. Конкретная версия Fabric API присутствует в [официальном репозитории Fabric](https://github.com/FabricMC/fabric/tree/0.141.1%2B1.21.11); использован Gradle 9.2.1 из [официального шаблона Fabric](https://github.com/FabricMC/fabric-example-mod/tree/86e800d). Контрольная сумма дистрибутива Gradle задана в wrapper.

## Установка

1. Установите Minecraft Java 1.21.11 и Java 21. Используйте [официальный Fabric Installer](https://fabricmc.net/use/installer/) для версии игры 1.21.11 и Fabric Loader не старее 0.18.4.
2. Установите Fabric API **для 1.21.11**, например `fabric-api-0.141.1+1.21.11.jar`, из [официальных каналов Fabric](https://fabricmc.net/use/installer/).
3. Скопируйте `release/survivor-toolkit-1.0.0.jar` (либо собранный `build/libs/survivor-toolkit-1.0.0.jar`, без `-sources`) и JAR Fabric API в папку `mods` соответствующего профиля Minecraft.
4. Запустите профиль Fabric. В мире нажмите **Right Shift**; повторное нажатие или **Esc** закрывает меню. В «Управление → Настроить клавиши Minecraft» можно переназначить меню, камеру и обычные игровые кнопки. Freecam по умолчанию — **F6**.

Если файл `release/survivor-toolkit-1.0.0.jar` отсутствует, соберите проект по инструкции ниже. На первом запуске сборки нужны подключения к официальным репозиториям Mojang, Fabric, Gradle и Maven Central.

## Сборка и запуск для разработки

В каталоге `survivor-toolkit`, с JDK 21 в `PATH` или `JAVA_HOME`:

```sh
./gradlew --no-daemon clean build
./gradlew --no-daemon runClient
```

Windows:

```bat
gradlew.bat --no-daemon clean build
gradlew.bat --no-daemon runClient
```

`build` запускает JUnit и создаёт remapped JAR в `build/libs/`. Wrapper скачивает Gradle с `services.gradle.org` и проверяет SHA-256; системный Gradle не нужен. Тестовый клиент использует отдельный каталог `run/`, а не установку пользователя.

## Возможности и границы

- **Warden Alert** выключен по умолчанию. Обнаруживаются только уже загруженные, не невидимые вардены в радиусе и узком центральном конусе взгляда с проверкой прямой видимости. Уведомление и локальный стандартный звук настраиваются. Это намеренно консервативнее обычного поля зрения. Никакого отслеживания сквозь стены, маршрутов, атак или данных о незагруженных сущностях.
- **Auction Helper** — исключительно ручной калькулятор. Введите название, общую цену, количество и ориентир цены за предмет. Он показывает цену единицы и 64 предметов и выделяет результат в пределах ориентира. История последних 50 ручных расчётов хранится локально; она не считывает экран аукциона и не совершает покупки или ставки.
- **Quick Build Assist** только выводит название выбранного блока и добавляет акцент к стандартной подсветке выбранного слота. Назначение клавиш и удержание/повтор взаимодействий остаются штатными функциями Minecraft. Нет генерации кликов, автоматического строительства или изменения задержек.
- **Freecam** доступна только в приватном одиночном мире, даже локальный мир, открытый по LAN, исключён. Она доступна только стоящему на земле игроку вне транспорта и использования предмета. Камера ограничена радиусом 12 блоков, загруженными чанками, препятствиями и прямой видимостью от глаз игрока. При движении персонажа, смерти, смене мира, появлении экрана или открытии LAN режим заканчивается. Во время режима обычные игровые действия заблокированы; физика игрока продолжает работать, никакие координаты не подделываются. Для своего сервера используйте spectator или отдельную серверную команду с явными правами администратора.
- На **каждом** многопользовательском сервере Warden Alert и Auction Helper заблокированы независимо друг от друга, пока пользователь не подтвердит разрешение правил для точного адреса сервера. Неизвестный адрес, например некоторые Realms/LAN-подключения, остаётся заблокированным. Разрешение можно отозвать. Проверка правил остаётся обязанностью игрока; мод не способен проверить правила сервера автоматически.
- Инструменты не обходят античит, не скрывают мод и не изменяют игровые пакеты. Если правила сервера запрещают мод — не используйте его.

## Конфигурация

`config/survivor-toolkit.json` содержит настройки интерфейса, оповещений, камеры, истории и подтверждённые адреса серверов. Обычные клавиши сохраняются Minecraft в `options.txt`. При загрузке значения проверяются; некорректные диапазоны заменяются значениями по умолчанию. Схема версии 0 мигрируется в текущую версию 1. Повреждённый файл или файл будущей версии **не перезаписывается**: используются временные значения по умолчанию и в меню показывается предупреждение. После исправления или резервного копирования и удаления только этого файла можно снова сохранить настройки.

## Проверки и известные ограничения

Независимые JUnit-тесты покрывают арифметику, валидацию и миграцию конфигурации, сохранение, серверные разрешения и запрет камеры в мультиплеере. Дополнительный опциональный smoke-тест запускает настоящий клиент в виртуальном дисплее и проверяет рендер GUI, переключение вкладки и обработчики мыши/текста/закрытия; он не создаёт мир и не подключается к серверу. Результаты конкретного запуска и ручные проверки следует смотреть отдельно: успешная компиляция не является подтверждением тестов варденов, реального подключения, смерти или поведения камеры в мире. Такие проверки необходимо выполнить вручную в тестовом мире/на разрешённом тестовом сервере.

Интерфейс использует встроенный шрифт игры, простой масштаб расположения и прокрутку. История показывает до пяти последних записей в меню, но хранит до 50. Ориентир применяется только к введённому вручную расчёту; автоматического анализа экранов серверов нет. Камера намеренно не является неограниченной noclip/freecam.

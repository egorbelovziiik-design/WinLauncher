WINLAUNCHER 1.0.0 — WINDOWS 10/11 x64
Твой мир. Твои правила.

ФАЙЛЫ

• WinLauncher-Setup.exe — настоящий NSIS-установщик, собранный Tauri.
  Рекомендуемый вариант. Установка для текущего пользователя, ярлыки и
  поддерживаемый механизм установки Microsoft Edge WebView2 Runtime.

• WinLauncher.exe — самостоятельный Windows x64 executable без установщика.
  Требует уже установленного Microsoft Edge WebView2 Runtime.
  Это не «полностью переносимый» режим: настройки и игровые данные также
  сохраняются в пользовательской папке приложения.

• SHA256SUMS.txt — контрольные суммы именно скачанных EXE-файлов.
• TESTING.md — подробный отчёт PASSED / FAILED / NOT TESTED и ограничения.
• BUILD-METADATA.json — точная сборка, ссылки на Windows CI и проверенные хеши.
• BACKEND-SMOKE, INSTALLER-SMOKE, NATIVE-SMOKE — фактические результаты проверок.

ЛОКАЛЬНЫЙ ОФЛАЙН-АККАУНТ (ДОБАВЛЕН ПО ВАШЕМУ ЗАПРОСУ)

Аккаунты → Добавить офлайн-аккаунт → Никнейм → Создать офлайн-аккаунт.
3–16 латинских букв, цифр или _. После сохранения он станет выбранным.
Microsoft Application ID для этого типа аккаунта не нужен. Ник и его регистр
определяют отдельный офлайн-UUID; он отличается от UUID Microsoft-аккаунта.
Профиль не подтверждает лицензию и не позволяет входить на защищённые серверы.
Используйте законно приобретённую игру. Это режим без Microsoft-авторизации,
а не гарантия полного отсутствия сетевых запросов: загрузка/проверка игровых
файлов требует сети. Отрисованный локальный игровой сеанс пока NOT TESTED.

ПЕРВЫЙ ЗАПУСК

1. Запустите WinLauncher-Setup.exe как обычный пользователь.
   Не запускайте лаунчер от имени администратора и не отключайте антивирус.
   Сборка не подписана Authenticode: Windows SmartScreen может предупредить.
   При сомнениях не запускайте файл; проверьте исходники, хеши и результаты CI.

2. Если выбран вход через Microsoft (не локальный аккаунт), откройте
   «Настройки → Интеграции → Microsoft».
   Нужен ваш публичный Application / Client ID зарегистрированного и
   разрешённого для Minecraft приложения с personal Microsoft accounts и
   public-client/device-code flow. Client secret не нужен. Регистрация сама
   по себе не гарантирует одобрение Minecraft Services. Инструкция — README
   репозитория. Чужие идентификаторы лаунчеров в сборку не встроены.

3. Войдите через Microsoft в аккаунт с лицензией Minecraft Java Edition.
   Пароль вводится только на официальном сайте Microsoft, не в лаунчере.
   Не отправляйте пароли, OAuth-токены или API-ключи в чат.
   Секретные токены сохраняются в Windows Credential Manager, а не в SQLite.

4. Создайте профиль, выберите Minecraft и загрузчик, настройте RAM.
   В автоматическом режиме лаунчер найдёт либо установит подходящую Java.
   Для проверенного сценария используйте Minecraft 1.21.4.
   Minecraft, библиотеки и ресурсы скачиваются из официальных метаданных;
   проверка хешей выполняется перед использованием файлов.

5. Для CurseForge введите свой действительный API-ключ в нативной форме
   настроек. Без ключа показывается настройка подключения, а не фейковый
   каталог. Запреты авторов на стороннее распространение не обходятся.

6. Для Discord укажите Application ID, загрузите Rich Presence image с ключом
   winlauncher в своём приложении Discord Developer Portal, запустите Discord
   Desktop и настройте видимость данных. Bot token не нужен.

ГДЕ ДАННЫЕ

Обычно: %APPDATA%\io.winlauncher.desktop\
Фактическую директорию показывает «Настройки → Пути».
SQLite хранит настройки и метаданные; data содержит Minecraft, runtime,
профили, моды, миры, резервные копии и логи. Каждый профиль изолирован.
При переносе data исходная папка сохраняется. Перед важными действиями
сделайте отдельную копию своих миров. Моды — сторонний исполняемый код;
совпадение SHA не гарантирует отсутствие вредоносного кода.

ЧТО ПОДТВЕРЖДЕНО

21 Rust-тест, 10 frontend-тестов, 12 браузерных тестов;
22 настоящих сценария Windows backend; установка/удаление NSIS.
Реально проверены установка Minecraft 1.21.4, Java 8/17/21/25,
Fabric/Forge/NeoForge/Quilt, Modrinth/Sodium/Iris, зависимости,
обновление отключённого мода, .mrpack, SQLite и перенос файлов.

ЧТО НЕ ПРОВЕРЕНО

Лицензионный Microsoft-вход и refresh, отрисованный игровой сеанс,
фактическая RAM/статистика работающей игры, Discord Desktop, keyed
CurseForge, восстановление пользовательских миров и полный нативный GUI
restart. GUI-автоматизация WebView2 не подключилась в CI. Не считайте
успешную сборку доказательством прохождения этих сценариев.

Интерактивная установка на чистом ПК, первый WebView2 bootstrap и SmartScreen
также требуют ручной проверки. Установщик был проверен в silent-режиме на
Windows CI, а не на всех конфигурациях Windows 10/11.

О ХЕШАХ УСТАНОВЛЕННОГО EXE

Tauri штатно меняет только метку __TAURI_BUNDLE_TYPE_VAR_UNK на
__TAURI_BUNDLE_TYPE_VAR_NSS внутри упакованного EXE. Поэтому хеш установленного
приложения отличается от самостоятельного WinLauncher.exe. Проверка
учитывает ровно это изменение, а затем сравнивает полный SHA256. Другие
различия не допускаются. Подробности и значения — TESTING.md.

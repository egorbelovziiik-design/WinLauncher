WINLAUNCHER 1.0.1 — FABRIC, JAVA И ДИАГНОСТИКА

Для существующего Fabric-профиля:
1. Обновите лаунчер, не удаляя папку игровых данных.
2. Выберите проблемный профиль и откройте «Логи».
3. Нажмите «Восстановить Fabric / Java» и подтвердите действие.
   Будут сброшены ручной путь Java, дополнительные JVM-аргументы и закрепление
   загрузчика. Лаунчер выберет управляемую Temurin и актуальный загрузчик,
   проверит файлы по контрольным суммам. Миры, моды и скриншоты сохраняются.
4. Если у вас моды, проверьте их совместимость именно с нужной версией.
   Моды для 1.16.5, 1.21.4 и 26.2 не взаимозаменяемы. Сначала проверьте новый
   чистый Fabric-профиль, затем добавляйте моды по одному.

Версии Minecraft:
«Версии Minecraft» → быстрый выбор 26.2 / 1.21.4 / 1.16.5 / 1.12.2 / 1.8.9
или поиск по всему официальному каталогу. В редакторе профиля также есть поиск.
Кнопки появляются только для версий, реально полученных от Mojang.
Для каждого поколения Minecraft создавайте отдельный профиль.

Java:
Автоматический режим использует управляемую Eclipse Temurin, а не случайную
Oracle Java из PATH. Java 8/17/21/25 выбирается по метаданным игры/загрузчика.
Ручной Java executable поддерживается как явный выбор пользователя.
Глобальные _JAVA_OPTIONS / JAVA_TOOL_OPTIONS / JDK_JAVA_OPTIONS / CLASSPATH
не вмешиваются в Java-процессы лаунчера. Для Java 9+ JVM-параметры передаются
через файл, чтобы избежать лимита длины командной строки Windows. Главный
класс и FabricMcEmu остаются на командной строке для драйверных профилей.

Если снова код 1:
Сам по себе код 1 не определяет причину. Откройте карточку диагностики в «Логах».
Фатальные отчёты JVM сохраняются внутри профиля, в .winlauncher-crashes.
Распознаются ошибки параметров/версии Java, памяти, библиотек, модов и OpenGL.
По кнопке «Папка отчёта» можно найти hs_err_pid*.log. Перед отправкой полного
исходного отчёта проверьте его на приватные данные/токены — это файл самой JVM.

Если в Problematic frame указан atio6axx.dll / atioglxx.dll:
Это сбой внутри AMD OpenGL. Восстановление Fabric не заменяет видеодрайвер.
Проверьте драйвер у производителя ПК/ноутбука или на официальном сайте AMD,
перезагрузите Windows, проверьте чистую Vanilla без шейдеров/оверлеев.
Не скачивайте отдельные DLL с посторонних сайтов и не отключайте антивирус.
Работа на конкретной AMD-видеокарте пользователя без повторного теста NOT TESTED.

Офлайн-аккаунт сохранён: Аккаунты → Добавить офлайн-аккаунт → Никнейм.
Он не даёт Microsoft-авторизацию и не является гарантией запуска без интернета.

WinLauncher.exe требует WebView2 Runtime. WinLauncher-Setup.exe — NSIS-установщик.
Сборка предварительная и неподписанная. Актуальные SHA256, source commit и
ссылки на проверки находятся в BUILD-METADATA.json, SHA256SUMS.txt и TESTING.md.
Проверка bootstrap означает реальное достижение инициализации клиента, но
не сертифицирует отрисованный игровой сеанс на любой видеокарте.

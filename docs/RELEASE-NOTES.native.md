# WinLauncher Native 1.0.0 preview

Добавлен локальный офлайн-аккаунт по нику: **Аккаунты → Добавить офлайн-аккаунт**. Ник — 3–16 латинских букв, цифр или `_`. Аккаунт сохраняется в SQLite, выбирается для запуска и удаляется без доступа к Microsoft Credential Manager.

- UUID соответствует Java `UUID.nameUUIDFromBytes("OfflinePlayer:" + nickname)`; регистр ника имеет значение.
- Офлайн-профиль явно отличается от Microsoft: нет поддельного OAuth-токена, скина или отметки «лицензия проверена».
- Microsoft-вход, refresh и проверка Entitlements сохранены для Microsoft-аккаунтов.
- Локальный режим не даёт доступ к серверам с проверкой Microsoft. Используйте свою законно приобретённую копию игры.
- Это офлайн-аккаунт, **не гарантия полностью автономного запуска без сети**: установка и проверка игровых файлов используют официальные сетевые метаданные.
- Существующие релизы другого канала не изменены. Нативное приложение проверяет обновления только в своём канале `winlauncher-native-v*`.

## Скачать

`WinLauncher.exe` — отдельный Windows x64 EXE; нужен установленный WebView2 Runtime.

`WinLauncher-Setup.exe` — поддерживаемый Tauri NSIS-установщик для текущего пользователя.

SHA256 опубликованы в `SHA256SUMS.txt` и `BUILD-METADATA.json`. Это предварительная **неподписанная** сборка: Windows SmartScreen может показать предупреждение. Не отключайте антивирус.

## Проверки

Релиз публикуется только после Rust/frontend-тестов, успешных реальных backend-сценариев (включая сохранение, выбор и удаление офлайн-аккаунта) и установки/удаления NSIS. Актуальные подробности — приложенные `TESTING.md` и JSON-отчёты с точным source commit.

**NOT TESTED:** отрисованный игровой сеанс в локальном или Microsoft-режиме; полный нативный GUI/WebView2, Microsoft OAuth с реальной лицензией, Discord Desktop, keyed CurseForge и восстановление пользовательских миров. Успешная сборка, создание локальной идентичности и установка файлов не выдаются за эти проверки.

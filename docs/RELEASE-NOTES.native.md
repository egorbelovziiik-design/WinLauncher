# WinLauncher Native 1.0.1 preview — Fabric / Java / версии Minecraft

- Автоматическая Java теперь выбирает управляемую Temurin, а не случайную Oracle Java из PATH. Незавершённые staging-runtime не используются.
- Посторонние глобальные JVM-параметры не вмешиваются в запуск. Ручной Java executable остаётся явным выбором.
- Относительные управляемые пути не кодируют кириллицу из каталога пользователя в JVM argument files. Файловый путь `@...` также относительный; нестандартные не-ASCII JVM-опции передаются напрямую.
- Java 9+ использует JVM argument files для длинного classpath Windows; главный класс и официальный FabricMcEmu остаются видимы драйверу в командной строке. Microsoft-токены в файл JVM-параметров не записываются.
- Сохраняются опубликованные Fabric SHA256/SHA1 библиотек; исправлено наследование legacy game-аргументов, сохранение native-classifier библиотек и минимальной версии Java.
- **Логи → Восстановить Fabric / Java**: повторная проверка файлов, актуальный загрузчик и управляемая Java, без удаления миров и модов. Сбрасываются ручной runtime, версия загрузчика и дополнительные JVM-аргументы — только после подтверждения.
- Поиск по всему каталогу Mojang и быстрый выбор **26.2, 1.21.4, 1.20.1, 1.19.2, 1.18.2, 1.16.5, 1.12.2, 1.8.9**. Никаких выдуманных записей: только версии, подтверждённые официальным API.
- Диагностика аварий JVM/OpenGL, параметров Java, памяти, библиотек и модов вместо одного «код 1». Читаются и старые hs_err в профиле. Принудительная остановка пользователем отдельно помечается, а не объявляется поломкой Fabric.

## Важное ограничение по скриншоту пользователя

`EXCEPTION_ACCESS_VIOLATION` с `Problematic frame: atio6axx.dll` — сбой внутри AMD OpenGL. Мы не подменяем драйвер DLL-файлами, не удаляем пользовательские моды/миры и не обещаем исправить аппаратно-драйверную проблему на неизвестном ПК. Нужна проверка подходящего драйвера и повторный тест на машине пользователя.

Публикация разрешена только после реальной установки и JVM-bootstrap **Fabric 1.21.4, 26.2, 1.16.5**, проверки старых Vanilla-релизов, Rust/frontend-тестов и NSIS install/uninstall. Bootstrap доказывает достижение инициализации клиента, **не отрисованный игровой сеанс**. Фактические результаты — в TESTING.md/JSON. Microsoft OAuth, Discord Desktop и keyed CurseForge без пользовательских настроек/аккаунта остаются NOT TESTED.

Офлайн-аккаунты по нику сохранены. Сборка Windows x64 предварительная, без Authenticode-подписи. Отдельному EXE нужен WebView2 Runtime; также приложен настоящий NSIS-установщик.

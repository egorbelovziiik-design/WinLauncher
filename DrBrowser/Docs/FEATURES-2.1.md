# DrBrowser 2.1: возможности и границы

## Что добавлено

- Меню профиля — отдельный WPF Popup поверх нативного WebView2, с прокруткой,
  аватарками-градиентами, своим фото, именем, темами и быстрыми действиями.
- DrSearch — собственная страница результатов, локальный поиск по истории/закладкам,
  сетевые результаты из DuckDuckGo HTML и переходы в Google/Яндекс/Bing/DDG.
  Это **не собственный поисковый индекс интернета**. Сетевой провайдер может отказать
  или изменить разметку; в таком случае показана ошибка и ссылки на поисковики.
- DrMusic — локальные файлы, категории, радио, мини-плеер, поиск по публичным
  каталогам iTunes/Deezer с 30-секундными превью. Яндекс Музыка открывается на
  официальном сайте: его авторизация, доступность и подписка действуют как обычно.
  Аудио Яндекс Музыки не копируется, DRM не обходится.
- DrGuard — правила URL, предупреждения, список исключений, журнал и запуск
  проверки файлов установленным Microsoft Defender. Это **не собственный антивирус**,
  не сертификация безопасности файла. Если Defender недоступен — проверки нет.
- DrAI Local — свой детерминированный текстовый движок: извлечение предложений,
  ключевые слова, статистика, простой анализ структуры кода. Это **не обученная LLM**
  и он не может ответить на любой вопрос или распознать картинку.
- DrAI Cloud — диалог, перевод, написание текста через пользовательский
  OpenAI-совместимый endpoint. Ключ защищён Windows DPAPI.
- Фото: кнопка «Фото» прикрепляет PNG/JPEG до 5 МБ. Отправка — только после
  нажатия «Отправить», через API с vision-моделью. Имя без пути, изображение и чат
  остаются в памяти приложения, не сохраняются в SQLite/JSON. «Очистить» удаляет чат
  и вложение. Изображения из последних 12 сообщений могут передаваться повторно
  как контекст. Провайдер может тарифицировать запрос и хранить данные по своей политике.
  HTTPS обязателен, кроме локального HTTP endpoint на loopback.

## Фото, видео и генерация

Анализ фото требует подходящей мультимодальной модели у провайдера и ключа.
Воспроизведение видео на сайтах выполняет WebView2, в рамках поддерживаемых кодеков/DRM.
**Загрузка и анализ видеофайлов в DrAI, генерация фото, видео и музыки не реализованы.**
Для вопроса по видео можно вручную сохранить кадр и приложить его как PNG/JPEG.
Не выдаём текстовый ответ за созданный медиафайл или локальную нейросеть.

## Проверки

Актуальные результаты — `screenshots/selftest-report.txt`, `smoke-report.txt`.
Проверка парсера на тестовом JSON не доказывает доступность живого каталога.
Облачные ответы и распознавание фото без пользовательского ключа не проверяются.
Результат Microsoft Defender зависит от установленного движка и его сигнатур;
отдельного испытания на реальных вредоносных файлах не проводилось.

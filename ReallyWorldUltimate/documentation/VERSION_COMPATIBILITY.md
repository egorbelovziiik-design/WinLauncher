# VERSION_COMPATIBILITY.md — Матрица совместимости Minecraft 1.21.4–1.21.11

## 1. Архитектура мультиверсионной поддержки

Сборка **ReallyWorld Ultimate** спроектирована для полноценной работы клиентов **Minecraft Java Edition `1.21.4` – `1.21.11`** (протоколы `769` – `774`).

### Выбранная серверная конфигурация
- **Основное рекомендуемое ядро:** **Purpur `1.21.11` (build `#2568`)** или **Paper `1.21.11` (build `#116`)**
- **Требуемая версия Java:** **Java 21 LTS** (Eclipse Temurin 21.0.8+ рекомендуется; версии 1.21.4–1.21.11 официально работают на Java 21)
- **Протокольный мост:** **ViaVersion `5.12.1+`** + **ViaBackwards `5.12.1+`** (ограничение входящих протоколов настроено строго на `769..774`, чтобы исключить эксплойты устаревших протоколов `<1.21.4`).
- **Альтернативный режим без ViaBackwards:** плагин `ReallyCore.jar` использует `api-version: '1.21.4'` и проверен на обратную совместимость Paper API, поэтому сборка может также запускаться на ядре **Purpur `1.21.4` (`#2416`) / Paper `1.21.4` (`#232`) + только ViaVersion**, если администратор предпочитает прямой forward-протокол без даунгрейда блоков `1.21.9–1.21.11`.

## 2. Матрица совместимости клиентских версий

Статусы согласно стандарту приёмки:
- `SUPPORTED` — полная поддержка протокола, GUI, предметов, экономики, PvP и ресурспака.
- `PARTIALLY_SUPPORTED` — подключение и все механики `ReallyCore` работают, но новые ванильные блоки/сущности более поздних патчей отображаются через эквиваленты `ViaBackwards` (если ядро `1.21.11`).
- `UNTESTED` — код и протокол совместимы теоретически/по спецификации, но живой интерактивный тест конкретным клиентом в изолированной песочнице не проводился (проверено автоматическими тестами на уровне Paper API и спецификации пакетов/ресурспака).

## 3. Проверка ключевых подсистем на 1.21.4–1.21.11

1. **Item Components & PersistentDataContainer:** `ReallyCore` использует стандартный типизированный API `ItemMeta#getPersistentDataContainer()` и `AttributeModifier` с `NamespacedKey` (совместимый со стандартом 1.21+), без прямых вызовов обфусцированного NMS. Все базовые материалы кастомных предметов выбраны из набора, присутствующего уже в `1.21.4` (`TOTEM_OF_UNDYING`, `HEART_OF_THE_SEA`, `AMETHYST_SHARD`, `NETHER_STAR`, `MACE`, `NETHERITE_SWORD`, `TRIDENT`, `FIRE_CHARGE`, `ENDER_EYE`, `SUGAR`, `BLAZE_POWDER` и др.), поэтому ни один кастомный предмет не превращается в «камень» при подключении с 1.21.4.
2. **GUI и Инвентари:** все 15 меню создаются через `Bukkit.createInventory(ReallyGuiHolder, size, Component)` со стандартными размерами `27`, `36`, `45`, `54` слота. Вся логика кликов защищена проверкой `InventoryHolder`, отменой `SHIFT_CLICK`, `NUMBER_KEY`, `SWAP_OFFHAND`, `DOUBLE_CLICK` и `InventoryDragEvent`.
3. **Голограммы и NPC:** используются серверные сущности `TextDisplay` и `Villager`, существующие во всех версиях `1.21.4–1.21.11` без пакетных хаков.
4. **Resource Pack (`pack.mcmeta`):** содержит одновременно:
   - `"pack_format": 46`
   - `"supported_formats": {"min_inclusive": 46, "max_inclusive": 75}` (для 1.21.4–1.21.8)
   - `"min_format": 46` и `"max_format": 75` (для 1.21.9–1.21.11)
   а также определения моделей в `assets/reallyworld/items/*.json` (стандарт 1.21.4+).

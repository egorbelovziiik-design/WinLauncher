# RESEARCH.md — Глубокое исследование публичных механик ReallyWorld (2022–2026)

> **Важное правовое и этическое примечание:**  
> Настоящий проект (`ReallyWorld Ultimate`) является **полностью самостоятельной оригинальной разработкой**, созданной с нуля на чистом Java 21 / Paper API и вдохновлённой публично наблюдаемым игровым опытом сервера ReallyWorld. В проекте **не используются** слитые плагины, декомпилированный закрытый код, украденные карты, чужие приватные конфигурации или защищённые товарные знаки. Все совпадения игровых жанровых механик реализованы независимым инженерным способом, а отличия и авторские расширения явно задокументированы ниже.

---

## Легенда уровней достоверности

- **CONFIRMED** — подтверждено официальным сайтом `reallyworld.ru` / `reallyworld.me`, официальным форумом `f.reallyworld.me` / `f.reallyworld.ru` или официальным Telegram-каналом новостей проекта (`t.me/s/rwinfo`).
- **LIKELY** — подтверждается многочисленными публичными обзорами игроков, видеогайдами YouTube/RuTube и описаниями вайпов 2024–2026 гг., но точные серверные формулы закрыты.
- **UNVERIFIED** — упоминается косвенно в пользовательских обсуждениях, точные параметры на стороне сервера не опубликованы.
- **CUSTOM** — собственная качественная инженерная реализация / балансное расширение в едином стиле анархии и гриферского выживания для версий Minecraft `1.21.4–1.21.11`.

## Задокументированные отличия от оригинала ReallyWorld

1. **Единая чистая архитектура 1.21.4–1.21.11 без устаревшего наследия 1.12.2/1.16.5:** сервер изначально спроектирован под Java 21, Paper Data Components и новые механики 1.21 (булава с баланс-капом, Display Entities для голограмм, ресурспак с поддержкой форматов `46`–`75`).
2. **Строгая безопасность привилегий:** в отличие от некоторых старых гриферских серверов, ни одна платная привилегия (кроме верифицированного персонала) не имеет доступа к неконтролируемому кику/бану обычных игроков без причины или выдаче бесконечного доната; команда `/grant` строго лимитирована квотой БД и пишет неизменяемый лог аудита.
3. **Оригинальный брендинг и ресурсы:** все текстуры Resource Pack, конфигурации, тексты и постройки спавна созданы специально для `ReallyWorld Ultimate` и распространяются под свободной лицензией без нарушения авторских прав третьих лиц.

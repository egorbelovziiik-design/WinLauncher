# Поставляемый файл Roblox

`LAST_CITY_3D.rbxl` — бинарное место **Living Meridian 0.3.0**, развиваемый вертикальный срез, не финальная игра.

Этот небольшой snapshot намеренно хранится в Git по запросу прямой GitHub-ссылки на `.rbxl`. Остальные сгенерированные файлы, логи и инструментарий находятся в игнорируемых `release-artifacts/` и `.local/`. Зависимости `node_modules/` и скачанный Blender runtime не коммитятся.

Сборка: `python3 last-city/tools/test.py` из корня репозитория. CI проверяет совпадение этого файла с результатом сборки. Контрольная сумма: `SHA256SUMS`.

Открыть в Roblox Studio: File → Open from File → Play (F5). [Инструкция](../README.md). **Открытие/Play именно 0.3.0 в Roblox Studio ещё не выполнены.**

**История:** 0.1.1 исправила некорректный `Terrain.PhysicsGrid` в первоначальной сборке; открытие 0.1.0 завершилось ошибкой. Пользовательские скриншоты подтверждают открытие и статический рендер выпущенной 0.2.0, но не Play новой 0.3.0.

# Поставляемый файл Roblox

`LAST_CITY_3D.rbxl` — бинарное место **Meridian Rebuilt 0.2.0**, вертикальный срез, не финальная игра.

Этот небольшой snapshot намеренно хранится в Git по запросу прямой GitHub-ссылки на `.rbxl`. Остальные сгенерированные файлы, логи и инструментарий находятся в игнорируемых `release-artifacts/` и `.local/`. Зависимости `node_modules/` не коммитятся.

Сборка: `python3 last-city/tools/test.py` из корня репозитория. CI проверяет совпадение этого файла с результатом сборки. Контрольная сумма: `SHA256SUMS`.

Открыть в Roblox Studio: File → Open from File → Play (F5). [Инструкция](../README.md). **Тесты в Roblox Studio ещё не выполнены.**

# Roblox Studio QA — обязательный следующий gate

Версия 0.1.0 не открылась у пользователя: **FAILED** (`unexpected end at offset 2`). В 0.1.1 исправлен `Terrain.PhysicsGrid`; пользователь подтвердил открытие 0.2.0 и запуск 0.3.0 скриншотами. Тест 0.3.0 выявил руки назад, неполную крышу и ненадёжный E у Виктора. Начальный статус открытия/Play/графики новой 0.4.0: **NOT TESTED**. Записывайте PASSED/FAILED только после реального действия в Studio и сохраняйте Output/видео/параметры теста.

## 1. Подготовка

1. Открыть `LAST_CITY_3D.rbxl` через File → Open from File.
2. Убедиться, что в Explorer есть Workspace/World, Shared, Remotes, Bootstrap, Client и Loading. В Workspace включён StreamingEnabled.
3. Включить Output. Запустить **Play F5**, не Run F8. Первый доступ к DataStore может занимать несколько секунд.
4. Непубликованный тест должен явно показать **ТОЛЬКО СЕССИЯ**. Для persistent теста — отдельная тестовая experience с API Services и `GameConfig.StudioUseDataStore=true`; по умолчанию Studio работает SessionOnly без API. Не включать доступ к production-профилям ради эксперимента.
5. Для опубликованного места выставить **Max Players = 9**. Сервер также отклоняет десятого игрока при отсутствии участка.

## 2. Полный основной путь

- [ ] На первом входе появляется приветствие. Start и Skip меняют сохранённое состояние; через T обучение можно повторить.

- [ ] Алекс доступен у северных ворот. E открывает диалог/портрет/камеру; «Что я получу?» меняет ответ; «Отказаться» закрывает диалог без задания.
- [ ] Принять «Первую кровь». Убить 5 обычных зомби. Проверить преследование, обход препятствий, удары, отсутствие урона через стену и однократное засчитывание смерти.
- [ ] Бегуны/тяжёлые не засчитываются как обычные зомби в первом задании.

## 4. Постройки, энергия, работники

- [ ] Найти свой участок по M. V вне участка отклоняется, внутри разрешается. Переключение плавное, Survivor снова управляется.
- [ ] B → стена: зелёный/красный призрак, поворот R, touch-кнопки, отмена. Сервер не принимает NaN, нецелую сетку, выход за границы, overlap, вход/терминал и палатку.
- [ ] Реальная цена списывается один раз; недоступная цена не оставляет постройку и не списывает часть материалов.
- [ ] Генератор ждёт 8 с, затем расходует 1 топлива/минуту и даёт 12 кВт. Удалить топливо со склада: после минуты питание отключается.
- [ ] Водокачка/мастерская/турель/прожектор реагируют на power budget. При demand > supply не все потребители получают питание.
- [ ] Farm без рабочего не производит. Назначенный рабочий физически доходит до неё, `atWork` становится true, еда появляется на складе. Ночью/в обед/при бегстве производство этого рабочего останавливается.
- [ ] Мастерская: каждые 30 с 2 scrap → 1 metal + 1 parts, только при питании и присутствующем работнике. Без input нет бесплатного output.
- [ ] Работники едят/пьют, нехватка снижает мораль. Низкая мораль уменьшает производство.
- [ ] Ремонт требует металл. Снос требует подтверждения, возвращает 25% материалов, повтор невозможен. Уничтожение зомби не возвращает стоимость.
- [ ] После 21:00 при наличии двух построек ночью могут прийти враги. Проверить подход к footprint, повреждение и турели. Лимит всего сервера ≤28.

## 5. Инвентарь, торговля и крафт

- [ ] Перестановка, фильтры, сортировка, split и use не меняют суммарное число вещей неожиданным образом.
- [ ] Еда/вода/аптечка восстанавливают реальный показатель. Полный показатель не расходует предмет.
- [ ] Склад работает только на своём участке. Отрицательные количества и несуществующий UID ничего не создают.
- [ ] Дроп ресурса доступен только владельцу в той же сессии, исчезает через 90 с/при выходе. Оружие/броня/чертежи не выбрасываются.
- [ ] Макс: сделки только рядом; реальные цены/stock/репутация, нет списания при полном рюкзаке. Coins не расходуются на ресурсы.
- [ ] Косметика: Coins уменьшаются один раз, цвет реального Tool меняется, характеристики не растут; повторное применение бесплатно.
- [ ] Виктор: улучшение +1 требует показанные Cash/материалы и увеличивает урон ровно на 6% базового. Максимум +10; ремонт восстанавливает durability.
- [ ] Крафт без мастерской отклоняется. Input списывается при старте, очередь одна, до срока/повторно забрать нельзя. Полный рюкзак сохраняет готовый заказ для более позднего получения.

## 8. Негативные команды (только своя test experience)

В Client Command Bar после сохранения резервной копии тестовых данных:

```lua
local r = game:GetService("ReplicatedStorage").Remotes
for _ = 1, 30 do
    r.QuestRemote:FireServer({action="claim", id="first_blood", coins=999999})
end
r.InventoryRemote:FireServer({action="withdraw", id="metal", count=-100})
r.BuildRemote:FireServer({action="place", id="generator", x=0/0, z=0, r=0})
r.InventoryRemote:FireServer({action="equip", uid="i999999999"})
```

Ожидание: нет новых ресурсов/Coins, нет ошибок сервера, нет двойной награды. Для проверки proximity повторить accept/claim вдали от NPC. Отдельно проверить spam и повторные сообщения после смерти/потери lease.

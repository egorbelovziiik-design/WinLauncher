# Дальнейшие этапы — НЕ готовые функции

Исходное ТЗ значительно больше текущего среза. В 0.5.0 уже есть два города, 9 личных участков, 16 глобальных NPC, строитель, quest-отряд, двусторонний server-timed вертолёт, 17 зданий, 12 вариантов заражённых, проходимая шахта и точная сохраняемая награда Glock. Ниже перечислены только оставшиеся этапы; это не обещание уже работающих кнопок.

## Ближайший gate — Roblox Studio 0.5.x

1. Пройти весь раздел 13 `STUDIO_QA.md`: импорт/F5, K/1, Степан, no-jump routes, второй город, два рейса, отряд, звук и все production buildings.
2. Повторить с 2, затем 9 клиентами; зафиксировать Output, видео, FPS, память, Physics, Network и MicroProfiler при лимите 34 заражённых.
3. Выполнить отдельный persistent test в опубликованной test experience: UpdateAsync, reconnect во время стройки/экспедиции/полёта, server handoff и BindToClose.
4. Исправить любые engine-specific дефекты grounding, collision, Motor6D, Pathfinding, streamed helicopter clone и mobile safe area. Автоматические тесты не дают этим пунктам PASSED.
5. Провести accessibility/gamepad/navigation и balance pass после исправления критических runtime ошибок.

## Следующее расширение систем

- Группы и роли с серверной ACL для добровольной совместной базы; обычный игрок не получает права на чужой участок.
- Durable ledger для межпрофильного обмена только после crash/retry/replay тестов. Текущий личный drop намеренно не является P2P-торговлей.
- Личный сундук, дополнительные рюкзаки, оружейные модули и броня по слотам.
- Трёхволновая оборона с читаемыми предупреждениями, server event state и сохранёнными результатами.
- Более богатые worker schedules, медицинские роли и ремонт инфраструктуры без offline resource farming.

## Исследование и сюжет

- Дополнительные доступные районы с настоящими задачами, а не фасадами/teleport menu.
- Документы, секреты и следующие главы после связки Меридиан → Новый Рубеж.
- Проверенные в Studio фазы и телеграфируемые атаки Бригадира; только затем новый босс.
- Репутационные последствия и выборы, которые сохраняются и не принимаются клиентом.

## Транспорт и город

- Один проверенный свободно управляемый автомобиль с server validation, топливом, ремонтом и гаражом. Текущие автомобили остаются декорациями.
- Вертолёт 0.5.0 остаётся фиксированным безопасным маршрутом; свободное пилотирование требует отдельной сетевой/физической архитектуры.
- Более глубокие production chains, аккумуляторная сеть, city upgrades и восстановление квартала с реальными условиями.

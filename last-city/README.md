## История исправления открытия файла — 0.1.1

Версия 0.1.0 **не открылась у пользователя в Studio**: `Error while decoding data: unexpected end at offset 2`. Причина в данных сборки: npm writer задавал `Terrain.PhysicsGrid` как `02 03`, теряя 12 завершающих нулевых байт. В 0.1.1 записывается полная 14-байтная пустая сетка из [эталона, сохранённого Roblox Studio](tests/fixtures/empty-terrain.json). Обычный binary roundtrip не проверяет внутренний формат этого поля — прежние тесты это пропускали.

Добавлены negative-control тесты на старый дефект и проверка сетки после сборки. Также исправлены несериализовавшиеся `Part.Color`, `Lighting.ClockTime`, `TextLabel.Font`: теперь используются `Color3uint8`, `TimeOfDay`, `FontFace`; неизвестные свойства завершают сборку ошибкой, а не теряются молча.

**Пользователь подтвердил открытие 0.2.0 и запуск 0.3.0 в Studio скриншотами, включая диалог по E; этот тест также выявил дефекты, исправляемые в 0.4.0. Именно 0.4.0 в Studio пока NOT TESTED.** Скачайте новый файл, не открывайте прежний `LAST_CITY_3D-first-light.zip` из временной папки. Сохраните `.rbxl` в обычную папку и откройте его через File → Open from File. Само открытие из ZIP не объявляется причиной сбоя: неверные данные были внутри нашей сборки.

## Запуск — без Rojo, Node.js и установки плагинов

1. Скачайте `.rbxl` по ссылке выше. Если открылась страница файла, нажмите **Download raw file**.
2. В **Roblox Studio → File → Open from File** откройте `LAST_CITY_3D.rbxl`.
3. Нажмите **Play / F5**, **не Run / F8**: для меню и управления нужен игрок.
4. Нажмите «Играть». Пройдите или пропустите обучение.
5. Откройте **View → Output** и следуйте [чек-листу Studio](docs/STUDIO_QA.md).

### Важное про сохранения

- Любой обычный тест Studio по умолчанию работает в **SessionOnly** без вызовов DataStore. Это явно указано в HUD/профиле. Закрытие теста в этом режиме теряет прогресс; кнопка сохранения не притворяется успешной записью в облако.
- Для проверки постоянных сохранений опубликуйте **отдельную тестовую experience**, затем включите **Game Settings → Security → Enable Studio Access to API Services** и установите `ReplicatedStorage/Shared/GameConfig.StudioUseDataStore = true`. Не тестируйте на production-данных: Studio с доступом к API может менять настоящие профили.
- В опубликованной игре ошибка загрузки **отменяет вход**, а не подменяет существующий профиль новым.
- `UpdateAsync`, единый профиль, сессионная блокировка, повторные попытки, автосохранение через 55 секунд, сохранение при выходе и `BindToClose` реализованы. Переход между серверами ожидает освобождения блокировки; после аварии она истекает через 180 секунд.
- Профиль хранит Coins, косметику, достижения и настройки. Кампании `coop` и `solo` имеют раздельные XP, Survival Cash, инвентарь, задания, постройки, работников и ресурсы.

## Что входит в этот срез

- **Расширенный 3D-район «Меридиан»**: убежище, разрушенные улицы, магазин MERIDIAN с полной крышей, промзона, лесная окраина, северный карантинный пост, восточный карьер, физически проходимая крытая шахта и девять жилых участков. 5 398 статических BasePart, StreamingEnabled 128/512.
- **Меню на фоне настоящего мира**: движущаяся камера, переход, Play/Continue, coop, tutorial, профиль, достижения, косметический магазин, настройки и changelog. Недоступный в Studio solo обозначен текстом, а не фиктивной кнопкой.
- **Одиночная кампания**: кнопка в опубликованной игре вызывает `TeleportAsync` с резервированием сервера; тип кампании определяется сервером. **Живая телепортация не проверена.** В Studio F5 даёт одного тестового игрока, но в разделе `coop`.
- **Кооперативный PvE-сервер до 9 игроков**: общие зомби, участие в победах, серверная репликация. Постройки и ресурсы принадлежат конкретным игрокам; общей базы, групповых ролей и P2P-торговли пока нет. Friendly fire отсутствует.
- **12 именных NPC плюс жители участков**: 15-сегментные R15-подобные Humanoid, явный разговор по **E**, портреты, индивидуальные детали, патрули и скорости. У Виктора маршрут вынесен из тесной геометрии, prompt не скрывается мелкими препятствиями, а сервер проверяет дистанцию и head-to-head line-of-sight.
- **Восемь заданий**: прежние сюжетные, побочные, исследовательские и ежедневные задания сохранены. Новое «Сердце шахты» принимается у Иры; сервер засчитывает только убийство Бригадира и атомарно выдаёт один Glock с 10 патронами в магазине плюс ровно 48 патронов 9 мм в резерве. При полном рюкзаке награда не делится и остаётся доступна у Иры.
- **Бой**: лом, мачете, кирка, P9, Glock, ПП Viper, дробовик M12 и карабин R4; три типа боеприпасов, серверный урон/raycast, настоящий многолучевой дробовик, автоматический огонь, магазины, перезарядка, износ, ремонт и улучшения +1…+10. Восемь ступеней заражённых: обычный наносит ровно 5 HP, затем урон возрастает до 18 у босса; тяжёлые классы имеют серверную броню. Процедурные позы рук направлены вперёд, без внешних AnimationId.
- **Инвентарь**: 24 ячейки / 180 кг, отдельный фильтр боеприпасов, обычный и тяжёлый бронежилеты, новые руда/уголь/химикаты/аккумуляторы/травы, рацион, обезболивающее и работающий энергетик; экипировка, использование, сортировка, перестановка, разделение стопок, личный дроп расходников/ресурсов и склад. Оружие/броню/чертежи выбрасывать нельзя. Дроп виден 90 секунд, забрать может только тот же владелец в той же сессии; при выходе он удаляется. Это сознательно исключает небезопасную передачу предметов между профилями.
- **Выживание**: здоровье, выносливость, голод, жажда, аптечки, броня, бег, тихий шаг, фонарик и три скорости расхода припасов. Приседание здесь — снижение скорости/заметности и камеры, не отдельная анимация тела.
- **Строительство**: баррикада, генератор, грядки, водокачка, мастерская, прожектор, турель, дизельная станция. Призрак, сетка, поворот, границы, зарезервированные вход/палатка, запрет реального пересечения при разрешённом касании краёв, серверное списание ресурсов, время готовности, здоровье, ремонт и снос с возвратом 25% материалов.
- **Экономика и жители базы**: генераторы расходуют топливо; распределение мощности отключает потребителей при дефиците; фермы/вода/переработка лома, два назначаемых работника, отдых/еда/бегство и мораль. В свободное время жители выбирают безопасные точки внутри участка, используют Pathfinding вокруг сохранённых зданий, не участвуют в проверке footprint и телепортируются в безопасную точку до появления новой постройки, если стояли внутри неё. Работник должен дойти к месту, чтобы участвовать в производстве. Офлайн-выработки нет; неиспользованная доля минуты топлива при выходе не переносится.
- **Крафт**: бинты, аптечка, обезболивающее, энергетики, три вида боеприпасов, переплавка руды, электроника, мачете, кирка и два бронежилета; готовая мастерская, ресурсы, время, сохраняемая очередь и однократная выдача заказа. Ручной крафт не требует назначения рабочего; автоматическая переработка требует рабочего и электричества.
- **Торговля**: ограниченный склад Макса, покупки/продажа ресурсов, изменение цен от наличия, скидка репутации. Survival Cash и постоянные Coins не смешиваются. Две косметические раскраски применяются к моделям оружия и сохраняются.
- **Локации**: аптека, полиция, АЗС с офисом, лагерь эвакуации, колонна, карьер с конторой/дробилкой и непрерывно проходимая шахта. В шахте есть подпорки, рельсы, вагонетка, рабочие лампы, руда, уголь, отдельные spawn-маркеры и физическая камера Бригадира — вход без телепортации.
- **Атмосфера**: 15-минутный цикл суток, туман/дождь/ясно, локальные капли дождя, фонари, ночные нападения на развитые участки, общий лимит 28 зомби, пул трассеров. Полной симуляции температуры/погоды и аккумуляторов нет.
- **UI**: рюкзак, журнал, диалог, карта с реальным положением и целью, база, строительство, крафт, торговля, оружейная, профиль, настройки, обучение. Keyboard/mouse и сенсорные действия; визуальная адаптация требует проверки на настоящем устройстве.

## Короткое прохождение

1. Подберите еду/воду рядом с начальным спавном, удерживая **E**. Откройте рюкзак **I**.
2. Найдите Алекса у северных ворот, нажмите **E**, примите «Первую кровь» **до** зачистки пяти целей.
3. За воротами победите 5 **обычных** заражённых. Бегуны и тяжёлые не заменяют цель этого задания. Лом наносит 28 урона с интервалом 0,65 с.
4. Вернитесь к Алексу и заберите награду. В **I** экипируйте P9 и нажмите **R**: новое оружие выдаётся с пустым магазином, патроны лежат отдельно.
5. **M** показывает ваш участок к югу от убежища. На участке нажмите **B**, выберите баррикаду, затем генератор. Ресурсы для первых построек уже лежат на складе.
6. **V** включает Commander только на вашем участке. **R** поворачивает призрак, ЛКМ размещает, **Esc** отменяет. На телефоне используйте кнопки размещения.
7. В **G** проверяйте запас топлива и мощность. Постройте ферму/водокачку, назначьте Миру или Льва. В мастерской появится переработка и крафт.
8. Для награды обучения завершите все 12 фактов и вернитесь в убежище: **T** или Настройки → Обучение → Забрать награду. Повтор не выдаёт ещё 500 Coins. Уже выполненные одноразовые сюжетные этапы засчитываются при повторе.
9. По восточной дороге за АЗС найдите Иру, нажмите **E** и примите «Сердце шахты». Войдите в шахту пешком, следуйте рельсам и победите Бригадира. Сервер сразу положит в рюкзак Glock **10/10** и добавит **48** патронов 9 мм.

## Управление

| Действие | Клавиша |
|---|---|
| Двигаться / прыгать | WASD / Space |
| Бег / тихий шаг | Shift / Ctrl |
| Атака / перезарядка | ЛКМ / R |
| NPC, сбор предметов | E (для предмета удерживать) |
| Фонарик / Commander | F / V |
| Рюкзак / квесты | I / J |
| Строительство / база / карта | B / G / M |
| Обучение / профиль | T / P |
| Лом / пистолет / аптечка | 1 / 2 / 3 |

В Commander WASD двигает обзор, колесо меняет высоту. Персонаж **не становится неуязвимым**. На мобильном доступны штатный стик Roblox и touch-кнопки атаки, бега, перезарядки, Commander и панелей.

После первой награды поговорите с Максом и Виктором: задания ведут в аптеку, полицию и офис АЗС. Ира ждёт у восточного карьера и выдаёт задание на босса шахты. В дверях нажимайте E; для закрытия отойдите из зоны движения створки.

## Что не обещается этой версией

**Не реализованы:** огромный мир из 20 локаций, 8-главная кампания, остальные боссы полного ТЗ, управляемый транспорт, PvP, армии/групповые права, передача ресурсов между игроками/базами, экспедиции, караваны, радиосети, полное дерево технологий, сезонные события и большая коллекция вооружения/брони. Их кнопок-заглушек нет. Следующие этапы: [ROADMAP.md](docs/ROADMAP.md).

**Музыка:** сторонние аудио ID не используются. Есть локальный UI-ping из поставки Roblox. Саундтрек, полноценные звуки оружия/зомби/двигателей и озвучка ещё не сделаны. Для музыки нужны собственные разрешённые Roblox audio assets; пустые настройки не выдаются за готовый звук.

## Исходники и воспроизводимая сборка

```text
last-city/
  src/ReplicatedStorage/Shared/          # конфиги, определения, фабрика моделей
  src/ServerScriptService/Domain/        # чистая логика, без Roblox API
  src/ServerScriptService/Services/      # серверные адаптеры / валидация
  src/ServerScriptService/Bootstrap.server.luau
  src/StarterPlayer/StarterPlayerScripts/
    Client.client.luau
    Controllers/                        # камера, бой, строительство, эффекты
    Views/                              # реальные клиентские интерфейсы
  src/ReplicatedFirst/Loading.client.luau
  tools/world/                          # модульная офлайн-генерация геометрии
  tests/                                # настоящие модули + API doubles
  releases/LAST_CITY_3D.rbxl             # единственный поставляемый binary snapshot
```

Linux/CI: нужны Node.js 22, Python 3, C++17, Make, curl. Для открытия готового места эти инструменты **не нужны**.

```bash
npm ci --prefix last-city/tools --no-audit --no-fund
bash last-city/tools/install-toolchain.sh       # Luau 0.743, pinned source SHA256
python3 last-city/tools/test.py                 # compile/analyze/test/build/verify/rebuild
```

Результат: `release-artifacts/last-city/` (исключён из Git). После успешной проверки обновите поставляемый snapshot:

```bash
cp release-artifacts/last-city/LAST_CITY_3D.rbxl last-city/releases/
cp release-artifacts/last-city/SHA256SUMS last-city/releases/
```

CI повторяет проверки и сравнивает все декодированные свойства, геометрию, ссылки и Source поставляемого snapshot с новой сборкой. Бинарная упаковка LZ4 может различаться между окружениями; две сборки в одном окружении обязаны быть побайтно идентичны. `tools/verify.mjs` читает файл **вторым независимым парсером**, проверяет все скрипты байт-в-байт, UTF-8, сервисы, remotes и StreamingEnabled. `tools/encoding.mjs` специально адаптирует UTF-8 к byte-string API бинарного writer; эту обработку нельзя удалять.

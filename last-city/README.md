# LAST CITY 3D
## DEAD WORLD: ULTIMATE SURVIVAL — First Light 0.1.0

**Настоящий проект Roblox на Luau. Первый вертикальный срез, НЕ законченная игра из полного ТЗ.**

[**Скачать LAST_CITY_3D.rbxl напрямую**](https://github.com/egorbelovziiik-design/WinLauncher/raw/refs/heads/arena/a850a844-winlauncher/last-city/releases/LAST_CITY_3D.rbxl)

Файл — бинарное место Roblox, а не переименованный XML и не веб-макет. Геометрия уже находится в `Workspace`; NPC, оружие и интерфейс создаются игровыми скриптами при запуске. Проект WinLauncher оставлен отдельно и не заменён этой игрой.

> **Что проверено:** компиляция 47 исходников, 97 доменных тестов, 61 проверка адаптеров на тестовых Roblox API, 39 проверок бинарного файла, повторяемая сборка. **Roblox Studio здесь недоступен: реальный Play Test, физика, Pathfinding, DataStore и мультиплеер — NOT TESTED.** Полный статус: [TEST_REPORT.md](docs/TEST_REPORT.md).

## Запуск — без Rojo, Node.js и установки плагинов

1. Скачайте `.rbxl` по ссылке выше. Если открылась страница файла, нажмите **Download raw file**.
2. В **Roblox Studio → File → Open from File** откройте `LAST_CITY_3D.rbxl`.
3. Нажмите **Play / F5**, **не Run / F8**: для меню и управления нужен игрок.
4. Нажмите «Играть». Пройдите или пропустите обучение.
5. Откройте **View → Output** и следуйте [чек-листу Studio](docs/STUDIO_QA.md).

### Важное про сохранения

- Неопубликованное место без доступа к API работает в **SessionOnly**. Это явно указано в HUD/профиле. Закрытие теста в этом режиме теряет прогресс; кнопка сохранения не притворяется успешной записью в облако.
- Для проверки постоянных сохранений опубликуйте **отдельную тестовую experience**, затем включите **Game Settings → Security → Enable Studio Access to API Services**. Не тестируйте на production-данных: Studio с доступом к API может менять настоящие профили.
- В опубликованной игре ошибка загрузки **отменяет вход**, а не подменяет существующий профиль новым.
- `UpdateAsync`, единый профиль, сессионная блокировка, повторные попытки, автосохранение через 55 секунд, сохранение при выходе и `BindToClose` реализованы. Переход между серверами ожидает освобождения блокировки; после аварии она истекает через 180 секунд.
- Профиль хранит Coins, косметику, достижения и настройки. Кампании `coop` и `solo` имеют раздельные XP, Survival Cash, инвентарь, задания, постройки, работников и ресурсы.

## Что входит в этот срез

- **3D-район «Меридиан»**: убежище, разрушенные улицы, доступный магазин MERIDIAN, промзона, лесная окраина, северный карантинный пост, шесть жилых участков. ~1 862 статических детали, StreamingEnabled 128/512.
- **Меню на фоне настоящего мира**: движущаяся камера, переход, Play/Continue, coop, tutorial, профиль, достижения, косметический магазин, настройки и changelog. Недоступный в Studio solo обозначен текстом, а не фиктивной кнопкой.
- **Одиночная кампания**: кнопка в опубликованной игре вызывает `TeleportAsync` с резервированием сервера; тип кампании определяется сервером. **Живая телепортация не проверена.** В Studio F5 даёт одного тестового игрока, но в разделе `coop`.
- **Кооперативный PvE-сервер до 6 игроков**: общие зомби, участие в победах, серверная репликация. Постройки и ресурсы принадлежат конкретным игрокам; общей базы, групповых ролей и P2P-торговли пока нет. Friendly fire отсутствует.
- **Алекс, Макс, Виктор**: физические Humanoid NPC, диалоги, портреты, proximity prompts, маршруты с бюджетом Pathfinding, репутация за задания.
- **Четыре задания**: «Первая кровь» (5 обычных зомби → 200 Coins, 150 XP, пистолет, 24 патрона); «Потерянные припасы» (3 разных ящика → 350 Coins, 250 XP, 2 аптечки); «Электричество для города» (20 металла + 10 проводов + 5 электроники и генератор → 500 Coins, 400 XP, чертёж); ежедневное дежурство после первого задания.
- **Бой**: лом, пистолет P9, карабин R4; серверный урон, дальность, raycast/line-of-sight, темп стрельбы, магазин, перезарядка, износ, ремонт и улучшения +1…+10. Три врага: обычный, бегун, тяжёлый. Есть простая процедурная анимация NPC и отдача/трассеры, не библиотека премиальных анимаций.
- **Инвентарь**: 24 ячейки / 180 кг, экипировка, бронежилет, использование, сортировка, фильтры, перестановка, разделение стопок, личный дроп расходников/ресурсов и склад. Оружие/броню/чертежи выбрасывать нельзя. Дроп виден 90 секунд, забрать может только тот же владелец в той же сессии; при выходе он удаляется. Это сознательно исключает небезопасную передачу предметов между профилями.
- **Выживание**: здоровье, выносливость, голод, жажда, аптечки, броня, бег, тихий шаг, фонарик и три скорости расхода припасов. Приседание здесь — снижение скорости/заметности и камеры, не отдельная анимация тела.
- **Строительство**: баррикада, генератор, грядки, водокачка, мастерская, прожектор, турель, дизельная станция. Призрак, сетка, поворот, границы, зарезервированные вход/палатка, пересечения, серверное списание ресурсов, время готовности, здоровье, ремонт и снос с возвратом 25% материалов.
- **Экономика**: генераторы расходуют топливо; распределение мощности отключает потребителей при дефиците; фермы/вода/переработка лома, два назначаемых работника, физический путь к работе, отдых/еда/бегство, мораль. Работник должен дойти к месту, чтобы участвовать в производстве. Офлайн-выработки нет; неиспользованная доля минуты топлива при выходе не переносится.
- **Крафт**: аптечка, патроны, бронежилет, готовая мастерская, ресурсы, время, сохраняемая очередь, однократная выдача заказа. Ручной крафт не требует назначения рабочего; автоматическая переработка требует рабочего и электричества.
- **Торговля**: ограниченный склад Макса, покупки/продажа ресурсов, изменение цен от наличия, скидка репутации. Survival Cash и постоянные Coins не смешиваются. Две косметические раскраски применяются к моделям оружия и сохраняются.
- **Атмосфера**: 15-минутный цикл суток, туман/дождь/ясно, локальные капли дождя, фонари, ночные нападения на развитые участки, общий лимит 24 зомби, пул трассеров. Полной симуляции температуры/погоды и аккумуляторов нет.
- **UI**: рюкзак, журнал, диалог, карта с реальным положением и целью, база, строительство, крафт, торговля, оружейная, профиль, настройки, обучение. Keyboard/mouse и сенсорные действия; визуальная адаптация требует проверки на настоящем устройстве.

## Короткое прохождение

1. Подберите еду/воду рядом с начальным спавном, удерживая **E**. Откройте рюкзак **I**.
2. Найдите Алекса у северных ворот, нажмите **E**, примите «Первую кровь» **до** зачистки пяти целей.
3. За воротами победите 5 **обычных** заражённых. Бегуны и тяжёлые не заменяют цель этого задания. Лом наносит 28 урона с интервалом 0,65 с.
4. Вернитесь к Алексу и заберите награду. В **I** экипируйте P9 и нажмите **R**: новое оружие выдаётся с пустым магазином, патроны лежат отдельно.
5. **M** показывает ваш участок к югу от убежища. На участке нажмите **B**, выберите баррикаду, затем генератор. Ресурсы для первых построек уже лежат на складе.
6. **V** включает Commander только на вашем участке. **R** поворачивает призрак, ЛКМ размещает, **Esc** отменяет. На телефоне используйте кнопки размещения.
7. В **G** проверяйте запас топлива и мощность. Постройте ферму/водокачку, назначьте Миру или Льва. В мастерской появится переработка и крафт.
8. Для награды обучения завершите все 12 фактов и вернитесь в убежище: **T** или Настройки → Обучение → Забрать награду. Повтор не выдаёт ещё 500 Coins. Уже выполненные одноразовые сюжетные этапы засчитываются при повторе.

## Управление

| Действие | Клавиша |
|---|---|
| Двигаться / прыгать | WASD / Space |
| Бег / тихий шаг | Shift / Ctrl |
| Атака / перезарядка | ЛКМ / R |
| NPC, сбор предметов | E (для предмета удерживать) |
| Фонарик / Commander | F / V |
| Рюкзак / квесты | I / J |
| Строительство / база / карта | B / G / M |
| Обучение / профиль | T / P |
| Лом / пистолет / аптечка | 1 / 2 / 3 |

В Commander WASD двигает обзор, колесо меняет высоту. Персонаж **не становится неуязвимым**. На мобильном доступны штатный стик Roblox и touch-кнопки атаки, бега, перезарядки, Commander и панелей.

## Что не обещается этой версией

**Не реализованы:** огромный мир из 20 локаций, 8-главная кампания, 6 боссов, транспорт, PvP, армии/групповые права, передача ресурсов между игроками/базами, экспедиции, караваны, радиосети, полное дерево технологий, сезонные события и большая коллекция вооружения/брони. Их кнопок-заглушек нет. Следующие этапы: [ROADMAP.md](docs/ROADMAP.md).

**Музыка:** сторонние аудио ID не используются. Есть локальный UI-ping из поставки Roblox. Саундтрек, полноценные звуки оружия/зомби/двигателей и озвучка ещё не сделаны. Для музыки нужны собственные разрешённые Roblox audio assets; пустые настройки не выдаются за готовый звук.

## Исходники и воспроизводимая сборка

```text
last-city/
  src/ReplicatedStorage/Shared/          # конфиги, определения, фабрика моделей
  src/ServerScriptService/Domain/        # чистая логика, без Roblox API
  src/ServerScriptService/Services/      # серверные адаптеры / валидация
  src/ServerScriptService/Bootstrap.server.luau
  src/StarterPlayer/StarterPlayerScripts/
    Client.client.luau
    Controllers/                        # камера, бой, строительство, эффекты
    Views/                              # реальные клиентские интерфейсы
  src/ReplicatedFirst/Loading.client.luau
  tools/world/                          # модульная офлайн-генерация геометрии
  tests/                                # настоящие модули + API doubles
  releases/LAST_CITY_3D.rbxl             # единственный поставляемый binary snapshot
```

Linux/CI: нужны Node.js 22, Python 3, C++17, Make, curl. Для открытия готового места эти инструменты **не нужны**.

```bash
npm ci --prefix last-city/tools --no-audit --no-fund
bash last-city/tools/install-toolchain.sh       # Luau 0.743, pinned source SHA256
python3 last-city/tools/test.py                 # compile/analyze/test/build/verify/rebuild
```

Результат: `release-artifacts/last-city/` (исключён из Git). После успешной проверки обновите поставляемый snapshot:

```bash
cp release-artifacts/last-city/LAST_CITY_3D.rbxl last-city/releases/
cp release-artifacts/last-city/SHA256SUMS last-city/releases/
```

CI повторяет проверки и сравнивает snapshot с исходниками. `tools/verify.mjs` читает файл **вторым независимым парсером**, проверяет все скрипты байт-в-байт, UTF-8, сервисы, remotes и StreamingEnabled. `tools/encoding.mjs` специально адаптирует UTF-8 к byte-string API бинарного writer; эту обработку нельзя удалять.

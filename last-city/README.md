# LAST CITY 3D
## DEAD WORLD: ULTIMATE SURVIVAL — IRON HORIZON 0.5.0

**Настоящий Roblox-проект на Luau: серверная игровая логика, физический мир, NPC, оружие, задания, строительство и сохранения. Это развиваемый вертикальный срез, а не законченная игра из полного ТЗ.**

> **Автоматический gate PASSED:** 52 Luau sources, 10 serialization, 7 roads, 117 domain, 89 mock-adapter и 110 binary assertions; две сборки побайтно совпали. Roblox Studio в среде разработки недоступен, поэтому импорт/Play 0.5.0, настоящая Humanoid-физика, Motor6D-позы, Pathfinding, звук, Streaming, живой DataStore и 2–9 клиентов остаются **NOT TESTED** до ручного gate. См. [TEST_REPORT.md](docs/TEST_REPORT.md) и [STUDIO_QA.md](docs/STUDIO_QA.md).

## Новое в 0.5.0

Полное описание: [UPDATE_0.5.0.md](docs/UPDATE_0.5.0.md).

- **Настоящий строитель Степан.** Он живёт на участке, отвечает на E, принимает точную цену из склада и рюкзака, серверно ищет ближайший свободный footprint, создаёт обычную функциональную постройку и физически идёт к месту работы. Неудачный заказ ничего не списывает.
- **Военный отряд по заданию.** После задания майора Макара Рада и Глеб появляются на базе игрока в военной броне с карабинами. Серверные команды: охранять базу, следовать за игроком и отправиться на сохраняемую 90-секундную экспедицию. Выстрелы расходуют настоящие `rifle_ammo` со склада; радиомачта с энергией усиливает добычу.
- **НОВЫЙ РУБЕЖ — второй город.** Задание Алекса требует 25 засчитанных убийств. После серверной выдачи награды открывается двусторонний маршрут. Шестисекундный полёт показывает движущийся вертолёт, вращающиеся роторы и кинематографическую камеру; сервер блокирует управление и только после таймера переносит персонажа.
- **Собственная база и помощники второго города.** Физически построены укреплённый гарнизон, командование, полевой госпиталь, склад, мастерская и гражданские кварталы. Макар выдаёт задание отряда, Нора лечит и выдаёт медицинское задание, Феликс открывает защищённую торговлю, Яна объясняет маршрут.
- **Исправленные и расширенные позы NPC.** Добавлены почёсывание головы, салют, работа строителя, вооружённое ожидание, прицеливание и состояние ранения. Ходьба остаётся противофазной; руки в разговорах и атаках направлены перед телом.
- **Без прыжков через стены.** У runtime Humanoid отключены `AutoJump`/`JumpPower`; пути работников, строителя, отряда и заражённых используют `AgentCanJump=false`. Заражённый ищет путь вокруг препятствия, а у блокирующей базы может атаковать настоящую постройку.
- **17 полезных типов построек.** Добавлены стальной забор, шипованная ловушка, вышка, военный генератор, теплица, очистка воды, патронный пресс, полевой медпункт и командная радиомачта. У каждого объекта есть серверная цена и игровая роль.
- **12 вариантов заражённых.** Коррозийный, Сталкер и Тюремщик ограничены вторым городом. Бригадир и сильные шахтные громилы создаются только на маркерах шахты. Обычный заражённый по-прежнему наносит ровно **5 HP**.
- **Улучшенный лом.** Модель получила крюк, загнутый конец, металлическую лапу и обмотку рукояти. Атака показывает замах, контакт и возврат. На новом профиле лом убран: первое нажатие **1** достаёт его, второе **1** убирает.
- **Рюкзак перенесён на K.** Старая клавиша I больше не открывает инвентарь. HUD, обучение, подсказки и документация используют **K**.
- **Авторизованный звуковой слой.** Фоновая пульсация, выстрелы, ближний бой, получение урона и вертолёт используют только файлы из встроенной поставки Roblox (`rbxasset://sounds/...`), без произвольных catalog ID. Музыка и эффекты имеют отдельную сохраняемую громкость.
- **Расширенная карта.** На общей карте показаны оба города, вертолётная площадка, статус блокировки маршрута, NPC и цели заданий; позиция игрока использует общую проекцию новых границ.

## Сохранённые регрессионные контракты

- Обычный заражённый наносит **ровно 5 HP** до применения брони.
- Обычный и тяжёлый бронежилеты можно купить или создать; военную броню можно создать после развития кампании.
- Награда шахты атомарна: **один Glock с 10/10 в магазине + ровно 48 патронов 9 мм в резерве**, 600 Coins и 650 XP. Полный рюкзак не выдаёт половину награды.
- Survival Cash и постоянные Coins не смешиваются; косметика не повышает урон.
- Friendly fire, произвольный PvP, чужое строительство, чужие рабочие и чужой личный дроп запрещены сервером.
- Обучение можно пропустить и повторить; 500 Coins + 100 XP + набор выдаются только один раз на профиль.
- Состояния заданий, оружия/магазинов, ресурсов, базы, строителя, отряда, настроек и обеих кампаний проходят нормализацию и сохранение.

## Запуск без Rojo и плагинов

1. Скачайте `.rbxl` по прямой ссылке выше. Если GitHub показывает страницу файла, нажмите **Download raw file**.
2. Откройте Roblox Studio → **File → Open from File** → `LAST_CITY_3D.rbxl`.
3. Откройте **View → Output**.
4. Запустите **Play / F5**, не Run / F8: интерфейсу нужен объект игрока.
5. Нажмите «Играть», затем пройдите или пропустите обучение.
6. Выполните обязательный [Studio QA](docs/STUDIO_QA.md). Не отмечайте визуальный/физический пункт PASSED без реального наблюдения.

### Сохранения

- Неопубликованный Studio-тест по умолчанию честно работает в режиме **ТОЛЬКО СЕССИЯ** и не обращается к DataStore.
- Для cloud-теста используйте отдельную опубликованную test experience, включите API Services и явно установите `GameConfig.StudioUseDataStore=true`. Не подключайте эксперимент к production-профилям.
- В опубликованной игре ошибка загрузки закрывает вход, а не заменяет существующее сохранение новым.
- Реализованы `UpdateAsync`, lease/token, retry, автосохранение, выход игрока и `BindToClose`. Живая проверка API остаётся NOT TESTED.
- `coop` и `solo` имеют отдельные кампании; Coins, косметика, достижения, tutorial reward и настройки общие для профиля.

## Игровые системы

### Мир и население

- Меридиан: убежище, девять частных участков, магазин, промзона, аптека, полиция, АЗС, лагерь эвакуации, карьер и физически проходимая шахта.
- Новый Рубеж: отдельный streamed-район с физическим основанием, дорогами, укреплённой базой, четырьмя учреждениями, жилыми блоками, ресурсами и восемью bounded spawn-маркерами.
- 16 глобальных именных NPC плюс два жителя, строитель и разблокируемые бойцы каждого игрока. Все runtime-актёры используют 15-сегментную R15-подобную артикуляцию и серверный E-prompt.
- NPC и заражённые имеют отключённый прыжок. Pathfinding ограничен бюджетом; дальние незаметные заражённые не создают постоянную нагрузку.

### Задания и маршрут

- 11 заданий: сюжет, исследование, строительство, daily, босс, второй город, военный отряд и медицина.
- Квестовые контейнеры имеют уникальные серверные ID; повтор одного объекта не дублирует прогресс.
- «ВТОРОЙ РУБЕЖ»: принять у Алекса после «Первой крови», победить 25 заражённых любого типа, затем использовать площадку у убежища.
- «ВОЗВРАЩЕНИЕ ГАРНИЗОНА»: у Макара победить 6 Коррозийных и одного Тюремщика; награда открывает бойцов и чертёж военного генератора.
- «ПОЛЕВОЙ ГОСПИТАЛЬ»: три разные медицинские цели в гражданском квартале второго города.

### Бой и предметы

- Лом, мачете, кирка, P9, Glock, ПП, дробовик и карабин; серверный raycast, cooldown, магазины, три типа патронов, reload, износ, ремонт и улучшения.
- Дробовик использует семь серверных лучей и отдельные shells. Автоматическое оружие стреляет при удержании.
- Броня уменьшает настоящий входящий урон и теряет durability.
- Инвентарь: 24 ячейки / 180 кг, стекло, бетон, стальные пластины, химикаты, батареи, травы, расходники и боеприпасы. Ресурсы можно переносить между рюкзаком и личным складом.

### База и экономика

- Ручное строительство и Степан используют одну серверную сетку, одинаковые границы/пересечения и общие реальные ресурсы.
- Постройки могут касаться краями, но не пересекаться внутренним объёмом. Жители не блокируют размещение и эвакуируются из уже принятого footprint до появления модели.
- Генераторы сжигают топливо; brownout отключает потребителей. Производственные здания проверяют энергию, input, назначенного работника, время смены, мораль и stock cap.
- Шипы наносят урон ближайшему заражённому и изнашиваются; турель расходует патроны со склада.
- Макс и Феликс проводят сделки только рядом; сервер хранит stock и рассчитывает дефицит/репутацию. Нора полностью лечит за 25 Survival Cash только рядом с собой.

## Короткое прохождение

1. Подберите стартовые припасы по E и откройте рюкзак клавишей **K**.
2. Нажмите **1**: лом появится в руках. Нажмите **1** снова: лом будет убран. Для боя снова нажмите **1**.
3. У Алекса примите «Первую кровь», победите 5 обычных заражённых и получите P9.
4. На своём участке откройте **B** для ручного строительства или поговорите со Степаном по E для автоматического заказа.
5. Выполните «ВТОРОЙ РУБЕЖ» у Алекса: 25 засчитанных убийств. На площадке у убежища удерживайте E и дождитесь настоящей посадки.
6. В Новом Рубеже поговорите с Макаром, Норой, Феликсом и Яной. После задания Макара бойцы появятся на вашей базе.
7. Вернитесь вертолётом, откройте **G** на базе и отдайте отряду приказ. Для стрельбы положите `rifle_ammo` на склад.
8. У Иры примите «Сердце шахты», пройдите шахту и победите Бригадира. Сразу проверьте Glock 10/10 и увеличение резерва ровно на 48.

## Управление

| Действие | Клавиша |
|---|---|
| Движение / прыжок | WASD / Space |
| Бег / тихий шаг | Shift / Ctrl |
| Атака / перезарядка | ЛКМ / R |
| Разговор, предмет, дверь, вертолёт | E |
| Фонарик / Commander | F / V |
| **Рюкзак / задания** | **K / J** |
| Строительство / база / карта | B / G / M |
| Обучение / профиль | T / P |
| Лом достать/убрать / P9 / аптечка | 1 / 2 / 3 |

На телефоне используются штатный joystick Roblox и touch-кнопки. В Commander персонаж остаётся уязвимым. Кнопка 1 — именно переключатель лома; K — новая клавиша рюкзака.

## Что не обещается в 0.5.0

Не завершены огромный мир из 20 локаций, восьмиглавная сюжетная кампания, свободное управление автомобилями/вертолётом, PvP, кланы и групповые роли, P2P-торговля, караваны, температура, сезоны, озвучка и большая библиотека оружия. В UI нет кнопок, которые притворяются этими системами.

Вертолёт 0.5.0 — рабочий серверно контролируемый маршрут между двумя площадками, а не свободно пилотируемый транспорт. Встроенный звук — безопасный процедурный слой из файлов Roblox, не заявка на оригинальный оркестровый саундтрек.

## Воспроизводимая сборка

```text
last-city/
  src/ReplicatedStorage/Shared/          # конфиги, определения, ModelFactory
  src/ServerScriptService/Domain/        # чистая транзакционная логика
  src/ServerScriptService/Services/      # Roblox-адаптеры и server authority
  src/StarterPlayer/StarterPlayerScripts/
    Controllers/                         # камера, бой, звук, эффекты, строительство
    Views/                               # responsive UI и карта
  tools/world/                           # детерминированная генерация мира
  tests/                                 # domain и Roblox API doubles
  releases/LAST_CITY_3D.rbxl             # поставляемый binary snapshot
```

Требования для сборки: Node.js 22, Python 3, C++17, Make и curl. Игроку для открытия готового файла они не нужны.

```bash
npm ci --prefix last-city/tools --no-audit --no-fund
bash last-city/tools/install-toolchain.sh
python3 last-city/tools/test.py
```

Pipeline компилирует Luau 0.743, запускает road/serialization/domain/mock suites, строит место, проверяет его независимым reader и повторяет сборку для byte-for-byte determinism. Артефакты пишутся в игнорируемый `release-artifacts/last-city/`.

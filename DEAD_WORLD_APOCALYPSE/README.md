# DEAD WORLD: APOCALYPSE

3D zombie-survival в открытом мире: город после вируса, 11 типов заражённых,
стрельба с хитбоксами по частям тела, выживание (голод, жажда, кровотечение,
инфекция, холод), машины с топливом, день/ночь и погода, орды и босс в лаборатории.

**Скачать игру для Windows:** раздел [Releases](../../releases) →
`DEAD_WORLD_APOCALYPSE_RELEASE.zip` → распаковать → `DeadWorldApocalypse.exe`.
Сборка из исходников: [docs/BUILD.md](docs/BUILD.md).

## Как играть

| Клавиша | Действие |
|---|---|
| WASD / мышь | движение / обзор |
| Shift | спринт (шумно!) |
| Ctrl / C | пригнуться (тихо) |
| Space | прыжок |
| ЛКМ / ПКМ | огонь или удар / прицеливание |
| R | перезарядка |
| 1–6, колесо | выбор оружия |
| E | подобрать, открыть дверь, сесть в машину, поговорить |
| F | заправить машину канистрой |
| Tab / I | инвентарь |
| L | фонарь |
| F1 / F3 / F5 / F9 | справка / FPS / сохранить / загрузить |
| Esc | пауза |

**Цепочка целей:** найти оружие → антибиотики в больнице → заправить пикап
у АЗС → убить ГИГАНТА в лаборатории (промзона). Дальше — просто выживайте:
ночью зомби больше, холоднее и темнее; выстрелы и крикуны собирают орды.

## Что внутри

- **Мир 360×360 м**: центр с многоэтажками и руинами, больница, полицейский
  участок, магазины, деревня с торговцем, АЗС, промзона с лабораторией,
  военный блокпост, лес. 4 дома с настоящими интерьерами и выбиваемыми дверями.
- **11 зомби**: обычный, толстяк, бегун, ползун, солдат, полицейский, врач,
  пожарный, крикун, мутант, босс ГИГАНТ. Зрение (конус + прямая видимость),
  слух, память, поиск, стаи и орды волнами.
- **10 видов оружия**: нож, бита с гвоздями, мачете, топор, пистолет,
  револьвер, штурмовая винтовка, дробовик, снайперская винтовка, арбалет
  (тихий!). Голова ×3, шлемы и броня у военных типов честно режут урон.
- **Транспорт**: седан, пикап, внедорожник, военный джип — топливо,
  повреждения, наезды. Плюс разбитые машины как декорации/препятствия.
- **Выживание**: консервы и вода, бинты от кровотечения, антибиотики от
  инфекции (100% = вы один из них), переохлаждение ночью и под дождём.

## Технологии и честность

- Все 3D-модели, анимации, текстуры и звуки **сгенерированы процедурно**
  скриптами: Blender 4.2 (`blender/`), PIL/numpy (`tools/`). Чужих ассетов нет.
- Движок: **Ursina/Panda3D (Python)**, сборка Windows — **PyInstaller**
  (GitHub Actions, `windows-latest`). Почему не Unreal/Godot — подробно и
  честно в [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md).
- Статус каждой подсистемы без прикрас: [docs/STATUS.md](docs/STATUS.md).
- Тесты: `python -B -m pytest tests/ -q` (логика, AI, баллистика, геометрия,
  анимации, сохранения) + `python main.py --smoke` (полный headless-прогон).


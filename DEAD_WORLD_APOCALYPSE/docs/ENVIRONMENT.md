# Этап 1. Отчёт об окружении и выборе технологий

## Что реально доступно в рабочей среде (проверено командами, 2026-10-30)

| Параметр | Значение |
|---|---|
| ОС | Linux (Debian 12, ядро 6.1), **не Windows** |
| CPU / RAM / диск | 2 ядра / 3.8 ГБ / ~20 ГБ свободно |
| GPU | отсутствует (программный рендер невозможен для UE5) |
| Python | 3.11.2 |
| Сеть | только `github.com`, `codeload.github.com`, `api.github.com`, `registry.npmjs.org`, `pypi.org` |
| Unreal Engine / Visual Studio | **не установлены и не могут быть установлены**: нет Windows, нет GPU, 4 ГБ RAM против минимальных ~16 ГБ и ~100 ГБ диска у UE5; бинарники Epic недоступны по сети |
| Godot 4 | бинарники лежат на `release-assets.githubusercontent.com` — хост **заблокирован** сетью песочницы (проверено: SSL-ошибка и через `github.com`, и через `api.github.com`). Сборка Godot из исходников (codeload доступен) на 2 ядрах/4 ГБ — многочасовая, а Windows export templates всё равно неоткуда взять |
| apt | репозитории Debian недоступны по сети |
| Blender | установлен официальным способом: модуль **`bpy` 4.2.23 LTS с PyPI** (Blender как Python-модуль). Для запуска без X-сервера собраны stub-библиотеки недостающих X/GL `.so` (headless-моделирование их не вызывает) |

## Принятое решение (по вашему же правилу Этапа 1)

> «Если компьютер не поддерживает Unreal Engine 5, предложи Godot 4 или другой подходящий движок»

Godot оказался недоступен по сети, поэтому выбран стек, который **реально доводит до Windows .EXE**:

- **Blender 4.2 (`bpy`)** — все 3D-модели, скелеты и анимации генерируются Python-скриптами (`blender/`).
- **Ursina Engine / Panda3D 1.10 (Python)** — игровой движок. Настоящая 3D-игра, не веб и не HTML.
- **PyInstaller на GitHub Actions `windows-latest`** — сборка настоящего `DeadWorldApocalypse.exe` под Windows 10/11 x64 (`.github/workflows/dead-world-windows.yml`). Локально в песочнице собирается и тестируется идентичный по коду Linux-бинарь.

## Что это значит честно

- Графика уровня UE5 (Nanite/Lumen) в этом окружении **невозможна физически**. Игра выполнена в стилизованной low-poly графике с динамическим светом, тенями, туманом, днём/ночью и погодой.
- Скелетная анимация существует в двух видах: полноценные риги с экшенами экспортированы в **GLB** (для Blender/Godot/UE), а рантайм Ursina использует иерархию частей с пивотами в суставах, которую двигают те же таблицы ключевых кадров (`assets/animations/zombie_animations.json`). IK ног в рантайме нет; есть процедурный боб и кроссфейды.
- Все ассеты (модели, текстуры, звуки, музыка) **сгенерированы процедурно** — лицензионно чистые, сторонних файлов в игре нет.

# FunTime Auction Helper Ultra Pro 1.0.0

Клиентский Fabric-мод для аукциона FunTime: премиальный тёмный GUI, анализ цен,
история цен и сделок, фильтры, стратегии, темы, конфиг-менеджер.

## Скачать

Возьмите **один** JAR под свою версию Minecraft:

| Файл | Minecraft | Java |
|---|---|---|
| `FunTimeAuctionHelper-1.16.5.jar` | 1.16.5 | 8 |
| `FunTimeAuctionHelper-1.21.4.jar` | 1.21.4 | 21 |
| `FunTimeAuctionHelper-1.21.11.jar` | 1.21.11 | 21 |

Нужны Fabric Loader 0.20.1 и Fabric API для той же версии игры. Оба файла — в `mods/`.

## Управление

* Открыть/закрыть GUI — **Ё** (та же клавиша, что `~` / `` ` ``), `ESCAPE` закрывает.
* Аварийная остановка «STOP ALL TRADING» — **F9**.
* Клавиши переназначаются в `SETTINGS`.

## Безопасность

* **MASTER AUTOMATION всегда OFF** после запуска игры, входа на сервер, потери соединения,
  ошибки и загрузки конфига. Автовосстановления нет.
* `AUTHORIZED_AUTOMATION` недоступен без официально разрешённой серверной интеграции,
  поэтому на FunTime мод ничего не покупает и не продаёт сам.
* Нет кликов по GUI, нет спама пакетами, нет обхода античита.

## Что проверено (реальный прогон CI)

* 21 юнит-тест ядра — 0 падений.
* Запуск в настоящем клиенте Minecraft 1.21.4 и 1.21.11 — self-test PASS, 13 проверок.
* Инспекция JAR: `fabric.mod.json`, entrypoint-класс, байткод 52/65/65.

## Ограничения

* Автоматические сделки на FunTime невозможны без разрешённого серверного API.
* Для 1.16.5 клиентский запуск в CI не выполнялся (dev-launch требует Java 9+).
* Разметка аукциона FunTime не документирована: профиль парсера нужно один раз подтвердить.

Подробности — в `BUILD_REPORT.md` внутри архива репозитория.

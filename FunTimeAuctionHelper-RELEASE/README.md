# FunTime Auction Helper Ultra Pro

Аукционный помощник для Minecraft (Fabric, только клиент) с премиальным тёмным GUI,
локальным анализом цен, историей цен и сделок, фильтрами, стратегиями и строгим
разделением «анализ» / «ручное подтверждение» / «автоматизация только через
разрешённый серверный API».

> **Честно о FunTime:** публичной документации на аукцион FunTime нет. Мод **не**
> выдумывает структуру аукциона, **не** кликает по GUI и **не** отправляет пакеты за
> игрока. Он читает только то, что сервер уже показал вам на экране, и разбирает это по
> **редактируемому профилю адаптера**. Пока профиль не подтверждён вами, офферы
> показываются в анализе, но не попадают в историю цен.

## 1. Что это

| | |
|---|---|
| Mod ID | `funtimeauctionhelper` |
| Сборки | `FunTimeAuctionHelper-1.16.5.jar`, `FunTimeAuctionHelper-1.21.4.jar`, `FunTimeAuctionHelper-1.21.11.jar` |
| Загрузчик | Fabric Loader 0.20.1 |

| Сторона | клиент (`environment: client`), на сервер ставить не нужно |
| Java | 8 для 1.16.5, 21 для 1.21.4 / 1.21.11 |
| Маппинги | official Mojang mappings |

## 2. Установка

1. Установите Fabric Loader для своей версии игры (1.16.5, 1.21.4 или 1.21.11).
2. Положите в `mods/` **Fabric API** для этой же версии и **ровно один** JAR мода,
   соответствующий версии игры.
3. Запустите игру, зайдите на сервер.
4. Нажмите клавишу **Ё** (физическая клавиша `, она же `~`; на английской раскладке
   это ` — GLFW key 96). GUI откроется и закроется той же клавишей или `ESCAPE`.

Клавиша обрабатывается по **физическому GLFW-коду**, поэтому русская и английская
раскладки работают одинаково. В чате и в любом другом экране GUI не открывается.

## 3. Что реально работает

### Управление
* Открытие GUI — **Ё** (`~`/`` ` ``), закрытие — **Ё** или **ESCAPE**.
* Переназначение обеих клавиш в `SETTINGS → KEY BINDINGS` (нажмите кнопку и введите клавишу).
* Отдельная горячая клавиша аварийной остановки (по умолчанию **F9**).
* GUI не перехватывает ввод, пока открыт чат или другой экран.

### Безопасность автоматизации
* **MASTER AUTOMATION** — по умолчанию **OFF**, и это не «настройка», а инвариант:
  * после запуска игры — OFF;
  * после входа на сервер — OFF;
  * после потери соединения — OFF;
  * после ошибки — OFF;
  * после загрузки конфига — OFF (сохранённое `true` игнорируется).
* **AUTO BUY** и **AUTO SELL** включаются только при включённом master-switch и
  независимы друг от друга.
* **STOP ALL TRADING** — отключает все переключатели, очищает очередь неподтверждённых
  операций, пишет событие в журнал и в уведомления. Уже исполненную сервером сделку мод
  не «отменяет» (это невозможно и не имитируется).

### Режимы
| Режим | Что делает |
|---|---|
| `ANALYSIS_ONLY` | только читает и анализирует; не покупает и не продаёт даже по кнопке |
| `MANUAL_ASSISTANT` | предлагает сделки, каждую операцию подтверждаете вы |
| `AUTHORIZED_AUTOMATION` | только при наличии разрешённого серверного API; без него режим **не выбирается** и честно показан как недоступный |

### Анализ цен (локально)
* price per item, price per stack, average, median, p25/p75, min, max;
* потенциальная маржа, оценка комиссии, оценка чистого профита;
* окно наблюдения, минимальное число сэмплов, предупреждение о слабых данных;
* формулировки «оценка», а не «гарантированная прибыль».

### История
* **PRICE HISTORY**: item id, имя, цена, количество, время, серверный профиль;
  график цены, средняя/медиана/min/max; **CSV export / import**, очистка по возрасту.
* **TRADE HISTORY**: операция, предмет, количество, цена, тип, время, результат,
  режим автоматизации. В расходы/доходы попадают **только `CONFIRMED`** операции;
  `PENDING`, `UNVERIFIED`, `STALE`, `REJECTED`, `CANCELLED` не считаются.

### Фильтры, избранное, стратегии
* Фильтры: имя, item id, min/max цена, цена за штуку, размер стака, категория,
  избранное, whitelist/blacklist; create/edit/delete/duplicate/save, шаблоны.
* Стратегии (только сигналы!): low price alert, price comparison, manual flip analysis,
  price history analysis, inventory selling planner.
* Совпадение с фильтром или стратегией **никогда** само по себе не создаёт сделку.

### GUI
Тёмная тема `#070910 / #11141E / #1A1E2C`, акценты `#8B5CFF`, `#5274FF`, `#00DBFF`,
статусы `#39DD9C`, `#FFC266`, `#FF5B78`. Страницы: Dashboard, Auction Analysis,
Buy Settings, Sell Settings, Strategies, Price History, Filters, Favourites,
Trade History, Notifications, Settings. Карточки, анимации, переключатели, ползунки,
выпадающие списки, подсказки, индикаторы, предупреждения, графики, поиск/скролл.

### Темы
`FUNTIME DARK`, `FUNTIME PURPLE`, `FUNTIME BLUE`, `FUNTIME CYBER`, `FUNTIME MIDNIGHT`,
`FUNTIME MINIMAL` + пользовательские темы в конфиге (primary/secondary/accent/background/
text, opacity, animation speed, corner radius).

### Конфиг
Create / Save / Load / Rename / Delete / Import / Export / Backup / Restore.
Атомарная запись (temp + move), автоматические бэкапы (до 10–20 файлов), профили в
`config/funtime-auction-helper/profiles/`.

## 4. Чего мод НЕ делает

* Не кликает по аукциону, не эмулирует игрока, не отправляет «торговые» пакеты.
* Не обходит античит, задержки, лимиты сервера.
* Не имитирует результат сделки: успешной считается только подтверждённая операция.
* Не покупает и не продаёт на FunTime автоматически — для этого нужен
  документированный серверный API, которого у проекта нет.
* Не выдумывает структуру GUI FunTime: профиль адаптера настраивается вручную.
* Не отправляет историю цен на сторонние серверы.

## 6. Известные ограничения

* Баланс игрока сервером не отдаётся → при включённой автоматизации покупка
  блокируется с сообщением «balance is unknown». Это сделано специально.
* Планировщик продаж из инвентаря показывает предметы и рекомендации, но выставляет
  лоты только вручную.
* Профиль адаптера по умолчанию — универсальные регулярные выражения; реальные
  строки FunTime нужно один раз подтвердить в `AUCTION ANALYSIS → CONFIRM PARSED LAYOUT`.
* Звук уведомлений реализован как настройка; фактическое воспроизведение зависит от
  доступности звукового движка клиента.

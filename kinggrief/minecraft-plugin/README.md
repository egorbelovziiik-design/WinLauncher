# KingGriefBridge — плагин выдачи

Paper · Purpur · Spigot (Java 17+). Выполняет команды выдачи из магазина KINGGRIEF.

## Как это работает

1. Магазин после подтверждения оплаты создаёт **задачи выдачи** (deliveries) — по одной на позицию заказа.
2. Плагин каждые N секунд отправляет `POST /api/minecraft/poll` с заголовком `X-Bridge-Secret`.
   Вместе с опросом передаются онлайн, слоты, версия и TPS (Paper/Purpur).
3. Магазин отдаёт очередь и помечает задачи как «отправлены». **Повторная выдача исключена**:
   ключ задачи уникален, а плагин получает только те, что ещё в статусе `pending`.
4. Плагин проверяет команду по белому списку префиксов и выполняет её от имени консоли
   в главном потоке сервера.
5. Результат отправляется в `POST /api/minecraft/ack`; задача закрывается, заказ получает статус «выдан».

## Сборка

```bash
cd minecraft-plugin
mvn clean package
# готовый jar: target/KingGriefBridge-1.0.0.jar
```

Поместите jar в `plugins/` сервера и перезапустите его.

## Настройка

`plugins/KingGriefBridge/config.yml`:

```yaml
base-url: "https://ваш-домен"
secret: "тот-же-секрет-что-в-.env"
server-id: "main"
poll-interval-seconds: 5
allowed-command-prefixes:
  - "lp "
  - "crates "
  - "relics "
  - "unban "
```

На сайте в `.env`:

```env
MINECRAFT_BRIDGE_SECRET=тот-же-секрет
```

В админ-панели: **Настройки → Minecraft-интеграция → Режим выдачи = bridge**.
Команды выдачи редактируются там же (плейсхолдеры `{player}`, `{rank}`, `{amount}`, `{case}`, `{order}`).

## Безопасность

- Плагин никогда не выполняет команды вне белого списка префиксов. Пустой список = запрет всех команд.
- Многострочные команды и команды без разрешённого префикса отклоняются и логируются.
- Секрет передаётся только в заголовке и должен быть длинным (`openssl rand -hex 32`).
- Используйте HTTPS: по HTTP секрет можно перехватить.
- Плагин не требует прав LuckPerms — команды выполняются консолью, как это делает администратор вручную.

## Команды

| Команда | Описание |
| --- | --- |
| `/kgbridge status` | Показать настройки и размер белого списка |
| `/kgbridge poll` | Запросить очередь немедленно |
| `/kgbridge reload` | Перечитать config.yml |

## Ограничения

- Сборка требует доступа к `repo.papermc.io` (Paper API). В этом репозитории jar не собран —
  исходники готовы, но бинарник нужно собрать у себя.
- Плагин не управляет выдачей напрямую в LuckPerms API: используется команда `lp user … parent add`.
  Если у вас другая система прав — измените шаблон команды в админ-панели.
- При потере связи команда остаётся в очереди; после восстановления она будет выдана при следующем
  опросе. Если задача уже была помечена «отправлена», но ack не дошёл, проверьте её вручную
  в разделе «Заказы» и при необходимости нажмите «Повторить».

# 📞 МемоЗвон

Telegram-бот на Python 3.11+, который создаёт голосовые **вымышленных** звонков. После успешной отправки voice-сообщения через 2–4 секунды появляется случайный сценарий «результата звонка». Он не является реальным разговором или записью ответа. Бот не звонит на телефонные номера и не отправляет сообщения третьим лицам: `/prank` создаёт ссылку, по которой получатель сам может начать взаимодействие.

Доступны 50 сценариев по категориям и три варианта реакции на каждый; для `alo` и `pizza` приведены подробные сценарии из задания. Сообщение с исходным заданием обрывается на сценарии №36, поэтому оставшиеся 14 сценариев и недостающие варианты реакций дополнены самостоятельно. Сценарии с организациями — сатира, не сообщения этих организаций. Никогда не сообщайте коды, пароли или данные карты по телефону.

## Установка

1. Создайте бота в [@BotFather](https://t.me/BotFather), получите токен и включите доступ к сети для Telegram и gTTS (Google Translate). gTTS бесплатен, но зависит от внешнего неофициального сервиса; доступность и ограничения не гарантированы. Текст сценария отправляется этому сервису для озвучки.
2. Установите **FFmpeg с libopus** и `ffprobe` в PATH. Например, Debian/Ubuntu: `sudo apt install ffmpeg`; macOS: `brew install ffmpeg`. На Windows установите FFmpeg и добавьте каталог `bin` в PATH.
3. В каталоге `MemoZvonBot`:

```bash
python3 -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # Windows: copy .env.example .env
# Впишите BOT_TOKEN в .env
python bot.py
```

Остановить: Ctrl+C. У запускаемого бота не должен быть одновременно активен другой экземпляр long polling. Если ранее был установлен webhook, удалите его через Telegram Bot API перед запуском. Бот не разворачивает веб-сервер. Для работы в группах настраивайте права и privacy mode через BotFather.

## Команды

- `/start`, `/help`, `/menu` — приветствие, справка и меню;
- `/list` — постраничный каталог с ID и кнопками;
- `/call pizza` — звонок по ID (например, `alo`, `pizza`, `windows`);
- `/random` — случайный сценарий;
- `/prank pizza` — добровольная отправка deep link через Telegram;
- `/stats` — число успешно отправленных голосовых и самый частый сценарий.

Голосовое отправляется в OGG/Opus. Результат содержит случайный вариант диалога и длительность из диапазона, указанных в библиотеке; он явно помечен как вымышленный. Задержка 2–4 секунды отсчитывается после успешной отправки voice. При сбое gTTS/FFmpeg/Telegram бот сообщает об ошибке, а отчёт не отправляет.

## Настройки и данные

Настройки берутся из `.env` рядом с `bot.py`: `BOT_TOKEN`, `DATABASE_PATH` (по умолчанию `data/memozvon.sqlite3`), `RATE_LIMIT_SECONDS` (1–86400, по умолчанию 15) и `TTS_CONCURRENCY` (1–20, по умолчанию 3). Токен не публикуйте. SQLite хранит Telegram user ID, ID сценария и время успешной отправки, а также время последнего запроса для ограничения частоты. Статистика общая для пользователя во всех чатах. Удалить данные можно остановив бота и удалив базу и её файлы `-wal`/`-shm`. Слот ограничения занимает и неуспешная попытка. Планировщик раз в сутки чистит записи ограничений старше 30 дней. Аудио обрабатывается в памяти; `temp/` оставлен для совместимости со структурой задания.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты не требуют Telegram-токена и сети; для полноценной проверки голосового установите FFmpeg и обеспечьте доступ к gTTS и Telegram. Локальные результаты не подтверждают доступность внешних сервисов.

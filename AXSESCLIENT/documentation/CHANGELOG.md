# AXSESCLIENT — Список изменений (Changelog)

## v2.0.0 — **OBSIDIAN AURORA** (2026-10-31)

### Главные обновления (RU)
1. **Исправлен баг рендера и обрезки ClickGUI (`Scissor Bug Fix`)**:
   - Полностью устранено смещение матрицы `GuiGraphics.enableScissor` на Minecraft `1.21.4` и `1.21.11` (где карточки модулей отображались только в правом нижнем углу и выходили за рамку окна).
   - Устранены горизонтальные полосы на полупрозрачных плашках HUD (переход на точные целочисленные `1px` скан-линии).
2. **Новый современный дизайн лаунчера и внутриигрового GUI (`OBSIDIAN AURORA`)**:
   - Полный редизайн `AXSESCLIENT.exe` (Avalonia UI): глубокая палитра Obsidian, градиенты Aurora, аккуратная навигация, русский язык по умолчанию + мгновенный переключатель `🌐 RU / EN`.
   - Новый двухколоночный ClickGUI с раскрывающимися прямо внутри карточки настройками (ПКМ / `▾`), чёткими пилюлями биндов `[—]` / `[KEY]` и чистой кириллицей/латиницей `1.0f` без наложений и размытия.
3. **Добавлены рабочие боевые функции (`КиллАура`, `Таргет HUD`, `ТриггерБот`)**:
   - **КиллАура (`KillAura`)**: умный авто-удар целей в радиусе (`2.5–6.0` блоков), учёт кулдауна 1.9+ или CPS, приоритет (`Дистанция` / `Здоровье` / `Угол`), фильтры (`Игроки`, `Монстры`, `Животные`), плавная наводка камеры, пауза при открытом инвентаре и авто-выключение при смерти.
   - **Таргет HUD (`Target HUD`)**: анимированная карточка цели при наведении или в бою (аватар с эффектом получения урона, плавная полоса ХП со шлейфом урона, точное ХП/проценты, броня и дистанция).
   - **ТриггерБот (`TriggerBot`)**: автоматическая атака валидной цели строго под перекрестием прицела.
   - Все **93 модуля** синхронизированы по ID между лаунчером и игрой на `1.16.5`, `1.21.4` и `1.21.11`.
4. **Настоящее выделение ОЗУ (`Real Hardware RAM Allocation`)**:
   - Реальное определение физической и свободной памяти ПК через Win32 `GlobalMemoryStatusEx`.
   - Интерактивный ползунок ОЗУ и быстрые пресеты (`2 / 4 / 6 / 8 / 12 / 16 ГБ`) с передачей точных флагов `-Xms` и `-Xmx` в процесс `java.exe` и автоматической очисткой системных лимитов `_JAVA_OPTIONS` / `JAVA_TOOL_OPTIONS`.
5. **Автоматическая установка Java 8 и Java 21**:
   - Автоматическая проверка, скачивание (основное зеркало Eclipse Temurin + резервное Azul Zulu OpenJDK), распаковка и привязка **Java 8** (для `1.16.5`) и **Java 21** (для `1.21.4` и `1.21.11`) с живым прогресс-баром в МБ.

---

### Highlights (EN)
- Fixed `1.21.4` / `1.21.11` `GuiGraphics.enableScissor` double-transform clipping bug and HUD horizontal scanline artifacts.
- Brand-new **OBSIDIAN AURORA** visual design across both the Windows x64 Avalonia Launcher and in-game ClickGUI, HUD, and Main Menu with pixel-snapped `1.0f` Russian & English localization.
- Added working **KillAura**, animated **Target HUD**, and **TriggerBot** across Minecraft **1.16.5**, **1.21.4**, and **1.21.11** (93 modules total).
- Implemented hardware-calibrated JVM RAM allocation (`GlobalMemoryStatusEx` + `-Xmx` + `_JAVA_OPTIONS` scrubbing) and zero-touch automatic **Java 8 & Java 21** installation.

# KingCaptcha

Исходный код проверки хаба Paper 1.21.4 / Java 21 и воспроизводимая сборка совместимого KingHub 1.2.4. Инструкция для установки: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Сборка: `python kingcaptcha/build.py --api-classpath "$PAPER_API_CP" --output-dir /tmp/kingcaptcha-release` (JDK 21). Программа не устанавливает плагины и не меняет серверные данные. `KingHub` остаётся необязательным потребителем публичного метода `isVerified(UUID)`, поэтому при отсутствии капчи его прежнее поведение сохраняется; с установленной капчей проверка выполняется на границе выбора и перехода.

Проверки в `tests/` используют отдельный временный Paper, тестовый плагин и клиентов Minecraft Protocol; настоящие миры, авторизационные данные и конфигурация не затрагиваются.

CI: `.github/workflows/kingcaptcha-paper.yml` собирает оба JAR и проверяет изолированный Paper с протокольными клиентами.

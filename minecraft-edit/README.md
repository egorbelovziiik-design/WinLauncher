# Minecraft Edit — "Sweater Weather" (The Neighbourhood)

Кинематографический Minecraft-эдит, **28.00 c**, 1920×1080, 60 fps, H.264.
Два игрока: `_qwerty_70` × `domep444543` (+ мобы: зомби, скелет, крипер, паук).

## Музыка

Оригинальный трек Spotify защищён DRM — скачать его нельзя, поэтому в видео звучит
**сгенерированная заглушка**: темп 163.6 BPM, оригинальные аккорды, без мелодии трека.
Бит-сетка выровнена под картинку: удары меча = кадры 78/100/122/182/204/358,
очки = 540, цепочка = 762, кепка = 848, нарастание 1160→1400, главный бас-удар = 1400.

Чтобы поставить настоящий трек: положить `sweater_weather.mp3` в `audio/` и выполнить
`python3 scripts/make_audio.py && python3 scripts/encode.py`.

## Как собрано

Полностью процедурно на Python: собственный софт-растеризатор (z-buffer, flat shading,
nearest-neighbour текстуры 16×16), блочные модели по ванильным пропорциям
(голова 8×8×8, тело 8×12×4, руки/ноги 4×12×4), рендер 960×540 → апскейл ×2 nearest
до 1920×1080, ffmpeg (libx264, 2-pass). Никаких сглаженных мешей и subdivision.

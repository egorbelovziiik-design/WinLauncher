# Minecraft Edit — "Sweater Weather"

Кинематографический Minecraft-эдит, **28.00 c**, 1920×1080, 60 fps, H.264 High, 24 Mbps.
Два игрока: `_qwerty_70` × `domep444543` (+ мобы: зомби, скелет, крипер, паук).

## Что исправлено в этой версии

* меч и бита машут по IK: клинок направляется в мировую точку, кончик меча
  попадает в моба, конец биты — в банкомат; бита держится двумя руками;
* числовой аудит `scripts/check.py` вычистил все пересечения пропов с телом
  (очки, цепочка, кепка, деньги в карманах);
* очки и кепка надеваются по дуге, а не сквозь череп;
* камера автокадрируется (`_fit_camera`) — ни обрезанных голов, ни пустых кадров;
* паук переделан в ванильного: тёмно-серый, 8 ног из двух сегментов, походка, красные глаза;
* убран пересвет на ударах, ослаблен DOF и затемнён ночной город;
* рендер нативно 1920×1080 (раньше 960×540 → апскейл ×2).

## Музыка

Официальный трек (Eminem — «Lose Yourself», Spotify) защищён DRM и скачан быть
не может. В `output/soundtrack.wav` лежит хип-хоп заглушка, выровненная по биту
под картинку; положите свой файл в `audio/sweater_weather.mp3` и запустите
`python3 scripts/make_audio.py && python3 scripts/encode.py`, чтобы подставить его.

## Сборка

```bash
cd scripts
python3 make_audio.py
python3 build.py --frames 1-1680 --width 1920 --height 1080 \
                 --out-width 1920 --out-height 1080 --out ../renders --workers 2
python3 encode.py
```

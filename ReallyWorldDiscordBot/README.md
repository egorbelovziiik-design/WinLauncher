## Быстрый старт за 1 минуту

1. Зайдите под своим аккаунтом **`robik0277`** на [Discord Developer Portal](https://discord.com/developers/applications) → нажмите **New Application**.
2. Во вкладке **General Information** скопируйте **Application ID**, откройте файл **`invite-generator.html`** (или впишите в `.env`) — вы сразу получите прямую ссылку приглашения бота в свой Discord!
3. Во вкладке **Bot** включите 3 тумблера **Privileged Gateway Intents** (`Presence`, `Server Members`, `Message Content`), нажмите **Reset Token** и вставьте токен в файл `.env` (`DISCORD_TOKEN=...`).
4. Запустите бота:
   - **Windows:** дважды кликните **`start.bat`**
   - **Linux / macOS / Хостинг:** `chmod +x start.sh && ./start.sh`
   - **Docker:** `docker compose up -d --build`
